# DAILY ACTION CHECKLIST · LA PROOF SPRINT (V3)

> Access-first, not post-and-hope. The job is to open ONE real room in LA, not to make content.

This is not travel content. This is proving the 10k Campaign Universe Buildout offer by opening a real room in LA. Run this every morning and every night without re-reading the whole runbook. The access move is the load-bearing step; the post is the byproduct that documents the proof. Full plan: `V3_BUILD/RUNBOOK_14_DAY.md`.

One-line goal (read it first, every morning): open ONE real room in LA today and prove the 10k Campaign Universe Buildout offer.

---

## MORNING (2 minutes)

- [ ] Read the one-line goal above.
- [ ] Name today's ONE access target (the warmest unworked row in `target_roster.csv`) and the ONE ask.
- [ ] Prep the value-first drop built for their thing (the micro-offer, the started frame, the one-pager). Draft only; do not send yet.
- [ ] Note any positive reply from yesterday that needs a same-day move.

## MIDDAY (the load-bearing action)

- [ ] Do the access move: send the value-first micro-offer (operator go), take the meeting, make the intro, ask for the capture (consent first), or move a warm reply toward a paid step. **Operator-approval gate before any send.**
- [ ] Respond to any positive reply inside 30 minutes.
- [ ] The moment a room opens, log the receipt the same day: fill one block of `ACCESS_RECEIPT_TEMPLATE.md`, then log the `rooms.csv` row with its campaign trace. No trace, no valid receipt.

## EVENING (build, document, advance, gate)

- [ ] Build one real piece of the campaign artifact for a target's thing (the real machine, not a mockup).
- [ ] Build at most one documentation post (content documents proof, never chases reach). **Operator-approval gate before any post.**
- [ ] Drop one value-first touch on a warm or warmable target.
- [ ] Advance one open loop (follow up a reply, confirm a meeting, send a committed next step on operator go).
- [ ] Run the 60-second end-of-day honesty gate below.

---

## 60-SECOND END-OF-DAY HONESTY GATE

- [ ] Did a real room move today, yes or no? (A real next step traceable to the campaign. A like, a follow, a "keep in touch," or a hallway hello is NOT a room.)
- [ ] If a room opened: is the receipt logged in `rooms.csv` with a real campaign trace? If not, log it now.
- [ ] If NO room moved: log "no room moved." If no room has moved for 2 days running (or the sprint midpoint, end of Day 7, is reached with zero rooms opened), fire the cold-access ladder tomorrow. Do not wait for Day 14.
- [ ] Never fabricate a room. A "did not fire" entry is a real result; a faked receipt destroys the one thing competitors cannot show.

---

## COLD-ACCESS LADDER (only when the 2-day trigger fires, run in order)

1. Go where the scene gathers (be physically at the LA venue, threshold, or event the target is in).
2. Show-dont-ask walk-in: carry the built artifact into the room.
3. Capture the micro-contact, follow up the same day.
4. Downgrade the ask, never the price (a 10-minute coffee, a referral; a referral to a real decision-maker IS an opened room).
5. The honest stop: if the full ladder runs and no room opens, log it honestly.

---

## DAILY GUARDRAILS

Value-first only. No mass-DM. No fabrication. Consent for any capture. Face-independent. Zero spend until the operator approves. Nothing sends, posts, generates, or names without the operator's explicit go (condition-met is eligible, not authorized).
