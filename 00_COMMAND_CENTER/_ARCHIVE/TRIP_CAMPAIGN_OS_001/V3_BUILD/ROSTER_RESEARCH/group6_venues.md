# Group 6: Venue / Scene Gatekeeper Roster (Category 25)

Category 25: studio, creative space, member club, or scene gatekeeper whose ROOM is itself the access point. These rooms gather the artists, brands, and founders the other categories cover. Read-only public discovery. No contact made, no login, no private data, zero spend.

Research date: 2026-06-26. All URLs were retrieved live via search then confirmed via fetch. Where a single dated public event was found, it is quoted verbatim. Where the room is a standing access point with no single dated event, that is stated honestly and the dated-moment confidence is set to INFERRED at best.
