# THE ONE-PERSON CAMPAIGN HOUSE , PRODUCTION PIPELINE v1 (2026-06-04)

> The first LIVE TEST of the optimized OS operating correctly. Not a business decision , a proof that the machine routes, gates, produces, self-checks, and extracts a skill. Faceless / off-grid / pseudonymous by default. Taste stays manual at the gates; mechanics get automated.

## Pipeline (14 stages, each with: owner, tool, gate)

| # | Stage | Owner | Tool/route | Gate before advancing |
|---|---|---|---|---|
| 1 | **Idea intake** | MANUAL (taste) | a one-line brief: premise + audience + drop type | output-usefulness + employer-conflict + legal (likeness/IP) |
| 2 | **World premise** | MANUAL (taste) | written world bible para (Claude assists) | identity-collapse (owned, not celebrity) + name-availability (brand/world name) |
| 3 | **Style-ref system** | semi-auto | Midjourney SREF codes + v3 LUXURY lock; lock 3-5 srefs | visual-doctrine (Nine Masters lane, no teal/orange) |
| 4 | **Character-ref (CRS)** | MANUAL approve / auto build | Nano Banana Pro , 14-ref sheet (front/side/3-4/back) | CRS mandate (no composite without validated CRS) |
| 5 | **Product/ref system** | semi-auto | reference images (product/wardrobe/props), image-order convention (1=base, 2=identity, 3+=refs) | source-quality (clean refs) |
| 6 | **Prompt generation** | AUTO (scaffold) | Six-Part Constraint Prompt scaffold (Subject+Action+Environment+Style+Lighting+Camera) | prompt-discipline gate |
| 7 | **Image generation** | AUTO + MANUAL select | Higgsfield/Nano Banana (4:5 IG / 9:16 vertical; 2K test -> 4K) | reject gates (plastic skin/identity drift/AI tells) + beat-source |
| 8 | **Motion generation** | AUTO + MANUAL select | Higgsfield Seedance/Kling; dialogue-free | composite/physics QA (grounding, edges) |
| 9 | **Edit / finish** | MANUAL (taste) | DaVinci Resolve (grain, halation, remove AI signature) + Lightroom for any real footage | Three-Tier Polish + beat-source gate |
| 10 | **Caption** | semi-auto | on-voice, no em-dashes, no AI-tell transitions | writing/voice gate |
| 11 | **Post** | AUTO (scheduled) | pseudonymous IG/TikTok/YouTube; brand handle only | employer-conflict + identity (no real name in metadata) |
| 12 | **Proof tracking** | AUTO | log saves/shares/DMs/print-intent/conversion to the proof-loop dashboard | source-freshness (timestamped) |
| 13 | **Kill / keep / scale** | MANUAL (judgment) | predefined signals vs the metric | proof-before-crowning (no scaling on a vibe) |
| 14 | **Reusable-skill extraction** | AUTO (mandatory) | capability harvest -> new skill if the motion repeats | capability-growth mandate |

## Automated vs manual (the taste line)
- **AUTOMATED:** prompt scaffolding, generation batches, format/aspect handling, posting/scheduling, proof logging, dashboard updates, skill extraction, file naming/backup.
- **MANUAL (taste still matters):** the premise, character design approval, the reject + beat-source gates on every frame, the final cut, the voice on captions, and the kill/keep/scale call. The machine never ships a frame that fails the reject gate; the operator owns every aesthetic and strategic gate.

## Legal/ethical guardrails (binding)
Owned characters only (no celebrity likeness). Pseudonymous brand + handles; no real name in metadata/WHOIS/payment descriptors. Personal devices/time/accounts; zero employer data/relationships/tools/domain. Form an LLC and route payments through it as revenue becomes real (payment-follows-proof). Platform ToS + AI-disclosure compliance.

## The 24-hour dry run (the live test of the machine)
Point the pipeline at ONE made-up brief and run stages 1-12 once, no real spend beyond credits:
1. Brief (1 line) -> 2. world para -> 3. lock 3 srefs -> 4. build 1 CRS + 1 hero frame -> 6/7. scaffold + generate one 4:5 hero -> 9. finish in DaVinci -> 10. caption -> 11. post under a fresh pseudonymous handle -> 12. log the signal.
**Success = the machine routed correctly, the gates caught at least one reject, an asset shipped that beats the source, and a skill candidate was logged.** That proves the OS operates, independent of whether the brief itself is "the business."

## Kill/keep/scale (for the test and any real run)
- **Kill:** zero organic signal in 72h AND the gates flagged the output as weak -> fix the frame/premise, not the distribution yet.
- **Keep:** any genuine save/DM/print-intent on $0 spend -> run 2 more drops.
- **Scale:** repeatable signal across 3 drops -> systematize into `os-campaign-house` skill + a paid services or product offer (per the possibility architecture).
