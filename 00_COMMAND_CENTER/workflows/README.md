# Workflows

Reusable playbooks for common tasks in sniped-media. Each file is a checklist
Claude (or you) can follow. They reference the skills catalogued in
`../SKILL_REGISTRY.md`.

| Workflow | Use when |
|----------|----------|
| `ship-change.md` | Making any code change end-to-end |
| `media-asset.md` | Generating images / video / audio for a campaign |
| `deploy.md` | Pushing a preview/production deploy |
