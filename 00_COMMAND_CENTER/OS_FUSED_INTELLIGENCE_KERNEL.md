## The principle

One input must wake the whole brain, not a few chunks. The brain is the fusion of:
the **always-on kernel** (the floor, every task) + the **doctrine graph** (concepts wired across sources) + the **routers + registry + gates** (the body that acts). All of it fires through one capstone.

---

## The one chain (every task)

```
INPUT
  -> os_intelligence_kernel.compact()      ALWAYS-ON: 11 law categories injected (the whole corpus floor)
  -> os_prime_router.classify()            modules wake
  -> os_doctrine_router.route()            doctrines + confidence (CERTIFIED/MIXED/PROVISIONAL)
  -> os_doctrine_graph (nodes/edges)       activate fused nodes -> pull real source families + atoms
  -> os_doctrine_graph.CONTRADICTIONS      navigate preserved tensions (never flatten)
  -> os_tool_router + os_tool_registry     route -> toolchain -> live status (REFUSES non-ACTIVE)
  -> gates                                 doctrine check + route validation + standing safety floor
  -> ARTIFACT -> LOG/DASHBOARD -> LEARNING LOOP
```

The capstone that runs the whole chain: **`os_execution_graph.py graph "<task>"`**.
