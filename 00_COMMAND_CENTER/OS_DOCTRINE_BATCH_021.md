## DOCTRINE ENTRIES (deduped)

### Production + Pipeline

**D-001 · Dual backup before closing laptop (non-negotiable)**
Card → Hot SSD + Warm HDD both verified bit-identical. Binary: both copies confirmed or the day is not done. Card stays full until next shoot.

**D-002 · No same-day editing**
Sleep on it. Do not fall in love with frames hours after shooting. Notion updated same-day; editing begins tomorrow.

**D-003 · Folder structure lock**
Every shoot gets identical 9-subfolder tree per shoot type. Naming: SNIPED_YYYY-MM-DD_ClientLastName_TYPE_###.[ext]. No ad-hoc variations.

**D-004 · Five-pass cull system**
Pass 0 (AI auto-reject) / Pass 1 (manual reject refinement) / Pass 2 (mark keepers) / Pass 3 (3-5 star rate) / Pass 4 (color label: Red = heavy retouch, Yellow = standard).

**D-005 · Hero edit time cap**
12-15 min per Hero target. Over 25 min = downgrade to Select or ship as-is.

**D-006 · AI tool routing lock**
Lightroom + Evoto (Heroes) / Topaz Photo AI (sharpen on export) / Photoshop (Red frames + composites only) / Never AI subject generation on client work.

**D-007 · Storage tiers**
Hot (1-2TB SSD, 60 days) / Warm (8TB HDD, 12 mo) / Cold (8TB mirror, 1yr+) / Cloud (Heroes + Selects + Proofs only; RAWs never cloud).

**D-008 · 3-2-1 backup rule**
SD card in, Hot SSD, Warm HDD. Card unformatted until cloud verified. Cold monthly batch. Heroes + proofs + content auto-cloud via Backblaze B2.

**D-009 · Lightroom catalog architecture (16 rails)**
One annual catalog. Folder-disk mirroring. Smart Previews on import. One saved import preset. One metadata + copyright preset. Assisted culling. Color label system (5-tier). 10 Smart Collections. Locked-look develop preset chain. Tone curve signature. Color Calibration tier. AI mask stack. Generative Remove. Copy + Paste masks. 9 saved export presets. Virtual Copy "_BASE" snapshot discipline.

**D-010 · Content pipeline (1 shoot = 8 outputs)**
Heroes gallery / Selects tier / Proofs upgrade tier / BTS Reel / IG Carousel / LinkedIn POV / IG Stories / Archive masters.

### Pricing + Sales

**D-011 · Three-option architecture (always)**
Premium anchors first, mid second, walkable third. Never single quote. Premium positioned as insurance not cost. Brand System minimum $10K.

**D-012 · $1,500 Reset floor (hard)**
Pearl-network scope flexes, price holds. No discounting. Trade scope, never price. No volume language.

**D-013 · SNIPED sells methodology + outcome, not photos**
Direction Stack runs first (diagnose before prescribe). Sells LA founder portraits, full stop.

**D-014 · Refusal is positioning**
Walk from off-brand work. Never compromise-of-positioning "just this once." Named-client in-group signaling is the product. Expensive is the feature, not the bug.

### Trust + Authority

**D-015 · 8 trust signals**
Named clients / specific outcomes (numbers + dates + names) / published work in named outlets / methodology articulation / vulnerability about process / referral chain / refusal language / long-game proof.

**D-016 · 5 trust anti-patterns**
Vague claims / self-promotion-heavy copy / stock photography on case studies / hidden methodology / generic positive review quotes.

**D-017 · 3 authority-building loops**
Case study loop (client → outcome → published case → new client) / teaching loop (methodology → LinkedIn POV → expert recognition → inbound) / refusal loop (refuse off-positioning work → selective reputation → premium inquiries).

**D-018 · Trust Equation: T = (C + R + I) / S**
Weakest variable drives stuck deals. Raise Self-Orientation = kill conversion. Pricing is not in the equation.

### Outreach

**D-019 · VIB DM structure (locked)**
Specific compliment (not generic) / soft offer (no pressure) / proof (subtle, one signal) / hands-off ask (one yes/no). Platform calibration: LinkedIn = trust/professional; IG = mythology/aesthetic gravity. Never cross-post.

**D-020 · VIB failure modes (5 banned)**
Premature pitching / generic opens / volume language / begging tone / multi-CTAs.

### Operations + Scheduling

**D-021 · Monday = operational execution; Saturday = infrastructure**
Monday cockpit: 3 specific time-bound outcomes only. Cadence non-negotiables locked (2 LinkedIn POVs Tue+Thu, 1 IG carousel Wed, 5-10 VIB messages, 1 shoot or follow-up or case study). New strategy is Saturday's job.

**D-022 · Post-delivery 8-step compounding cadence**
Day 0: gallery delivery (locked template, 9 AM PT) + hospitality moment (non-negotiable). Day +1: Pixieset analytics. Day +3: soft check-in if no engagement. Day +7: feedback/testimonial + soft Op Kit touch. Day +14: Op Kit pitch (if signals warrant). Day +30: case study capture. Day +60: referral ask (warm, specific).

**D-023 · Strategic free is NOT discounted Reset**
Different SOP, not same-work-lower-price. Scope: 4-8 frames vs 8-12 for Reset. Explicit trade terms required (reach specificity, content rights, named credit). Refuse vague "exposure" trades.

**D-024 · Pre-shoot checklist mandatory**
Day-before full pass. Explicit weather and logistics contingencies. Mandatory gear check. Refuses "I'll just bring what I always bring."

### Hiring + Delegation

**D-025 · Retoucher hire gate: Phase B only**
Fires when Hero edit volume sustains 30+ per month for two consecutive months. Retoucher executes the methodology, never invents creative decisions. Off-limits: no preset modification, no new Smart Collections, no re-editing Green frames, no AI subject generation, no client comms.

**D-026 · Retoucher performance targets**
12-15 min per Hero. 12-16 Heroes per 4-hour session. 0 Green frames shipped that should have been escalated. 30-day ramp: Day 1 = 4-hour onboarding, 2 weeks supervised, 2 weeks sample-review only.

### AI Tool Rules

**D-027 · AI never produces a delivered photograph**
Anti-AI client moat is absolute. AI never replaces founder presence. AI never replaces Direction Stack methodology. Applies to all: Firefly, Seedream, Leonardo, Midjourney.

**D-028 · Seedream prompt assembly (mandatory elements)**
HEX palette + camera cheat code + environment from 7-environment rotation vocabulary + register. Version: 5.0 Lite for plates, 4.5 for identity preservation. No subjects generated.

**D-029 · Leonardo AI = internal alignment only**
Pre-shoot storyboard/moodboard for founder communication. Never delivered, published, or shown without explicit "this is reference, not the work" framing.

**D-030 · Firefly: utility on top of real photographs**
Generative fill, remove-people, text-to-template. Never generates the photograph itself. Berger rule holds.

### Strategic Governance

**D-031 · Reverse roadmap is locked**
Refuses ad-hoc redesign. Year 1-2 tactical moves are not roadmap-level questions. "Things change" is not a valid override.

**D-032 · 10 corpus-validated implications govern chassis-level decisions**
New phase, new lane, new offer tier, new business surface, major pivot all route through the implication grid. Not for daily tactical (content, outreach, pricing decisions).

**D-033 · Status psychology framing**
Founders buy premium photography for status signaling, not photos. Hidden-motive lens: buyers will not admit they signal status, so copy demonstrates elite tier without naming it. Selectivity over availability.

### Skill Intake + Ingestion

**D-034 · No blind installation**
Every external skill candidate classified: activate-now / convert-into-SNIPED-skill / store-reference-only / defer-until-tool-exists / reject-as-bloat.

**D-035 · Ingest immutability rule**
Raw export stored immutable. Edits happen in summary file only. No OS state mutation without explicit BJ approval. Triage is propose-and-await only.

**D-036 · Project ingestion 7-step flow**
Scrub credentials first. Store raw. Write 9-section summary. Update ledger. Mark source. Triage proposals (no auto-execution). Default for ambiguous content: archive.

Three different SLA figures appear: 5 days (post-shoot-same-day SLA reminder), 7 days (PRODUCTION_OS + strategic-free), 10 days (Op Kit). The 5-day vs 7-day discrepancy for Reset needs resolution. CURRENT_STATE.md is cited as the governing source; recommend checking it directly before crowning either number.

**CF-002 · Retoucher skill fire gate vs Phase B trigger specificity**
sniped-retoucher-onboarding states "Mo 6-9 per year" as the hire window. PRODUCTION_OS states "Retoucher Mo 6-9 trigger." But the skill fires on "30+ Heroes/month sustained 2 months" as the functional gate, which could occur earlier or later than month 6. The calendar-month gate and the volume-based gate are two different triggers that may not align. No resolution mechanism documented.

**CF-003 · Strategic free deliverable count range**
sniped-shoot-day-strategic-free states "4-8 frames." sniped-production-os states "Strategic Free Collab (compressed, 4 hr cap)" without specifying frame count. These are not in direct conflict but the frame count is only documented in one of the two places, creating a single point of failure if shoot-day-strategic-free is not read.

No contradictions found within: pricing floor, 3-option architecture, VIB failure modes, Trust Equation formula, anti-AI client moat, WWP proclamations application, Monday/Saturday split, Lightroom 16 rails, Seedream subject-generation refusal, ingest immutability rule.
