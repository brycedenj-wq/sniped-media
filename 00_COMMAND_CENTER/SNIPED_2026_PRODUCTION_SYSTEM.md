## 1. The standard

- **Velocity × ceiling.** Premium photography at premium turnaround. Mid-tier LA portraits ship in 4-8 weeks; SNIPED ships in 7 days.
- **One shoot = one multi-format multipack within 7 days.** Stills + motion + carousel + LinkedIn case study + scene-tagged delivery + print master per tier-A frame.
- **BJ's eye stays on cull + tier-A ceiling frames.** The machine handles all production drag in between.
- **Tier-A gets Photoshop ceiling.** Tier-B gets engine + Adobe MCP batch. Tier-C dropped or light-shipped.
- **Every shoot leaves system residue.** New register notes, new edit recipes, new scene contacts, new Cultural Doc candidates logged for compounding.

## 2. Six-stage machine

1. **Direction.** Direction Stack + Higgsfield concept board (3 frames per chapter at low spend) for alignment with model + MUA + studio. Pre-shoot prevents wasted reps.
2. **Capture.** BJ shoots Canon RAW + locks lighting per chapter + paired motion or BTS device for real Cultural Doc footage (never staged BTS).
3. **Sandbox + cull.** rawpy decode → OpenCV technical-quality + perceptual-hash scoring → top-K candidates surface to BJ. BJ eye selects ~6 tier-A + ~24 tier-B. Audit trail JSON sidecar per frame.
4. **Develop + retouch.** Adobe MCP base develop applies current register at scale. SNIPED Retouch Engine on tier-B (90 seconds per frame). Photoshop ceiling on tier-A only (30-45 min per frame). Evoto temporary bridge for emergency volume during transition; phased out when engine matches.
5. **Multi-format production.** Per tier-A frame: HERO color + Card B&W + 4:5 + 9:16 + LinkedIn + print master + Higgsfield motion teaser (10-15s) + caption draft + DM draft + Cultural Doc episode candidate when applicable. One frame → 8-10 deliverables programmatically.
6. **Distribution + scene density.** Pixieset delivery within 5 days + tagged IG drops + LinkedIn case study + Cultural Doc episodes monthly + print drops quarterly. Airtable proof log tracks every referral / repost / inquiry / collab generated per drop.

## 4. Retouch posture

- **v3 LUXURY is the current baseline, not the ceiling.** The next register sharpens or evolves through reps, not through doc revision.
- **Evoto is temporary bridge only.** Phased out when the SNIPED Retouch Engine v1 consistently matches or wins on the locked register. Not a permanent dependency.
- **Build the SNIPED Retouch Engine through reps.** Tune via real shoot frames; do not over-design the spec before the first proof cycle runs.
- **Tier-A frames route to Photoshop ceiling.** The absolute top frames still need the manual 30-45 min composite / retouch ceiling.
- **Tier-B frames route to engine + Adobe MCP batch.** 90 seconds per frame for the volume layer.
- **Tier-C frames dropped or light-shipped.** Not every captured frame needs the full pipeline.
- **The engine encodes the register as parameters.** Changing register = changing parameters, not rebuilding the workflow.

## 5. Higgsfield / Adobe / human role

- **Adobe (Lightroom + Photoshop + Adobe MCP + Evoto bridge).** Finishes the real photograph. Color, masks, retouch, ceiling composite, polish, delivery quality.
- **Higgsfield (CLI + skills + MCP).** Worlds, atmosphere, motion teasers, concept boards, campaign mythology. NEVER touches face / body / identity of the real captured subject.
- **Python + ImageMagick + exiftool + ffmpeg + rawpy + OpenCV.** Production infrastructure. Sandbox, batch ops, RAW decode, metadata, cull-assist, format conversion, comparison grids, audit logs.
- **Figma MCP.** Layout, presentation, dossier, deck, page-level brand consistency.
- **Pixieset + Drive + Airtable + Gmail.** Delivery, archive, proof log, client comms.
- **BJ.** Taste, cull, register sign-off, identity protection, tier-A ceiling, final per-frame approval. The eye is the moat; the machine handles the drag.
