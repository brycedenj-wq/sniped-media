## STALE-TOOL WARNING GATE (locked)
Section B and F of the Creator + AI-Production Field Manual, and the SREF Library, are **scrape-dated (2026)**. Before relying on any specific tool name, version, price, or SREF code from these sources:
1. Treat the item as `provisional / scrape-dated`, never as settled fact.
2. Verify the tool still exists, the version is current, and the price holds, before any build commit or client use.
3. Pin the version each pipeline was proven against (Blender MCP 5.1, UE 5.5+, Opus 4.x, Midjourney v8.1) and re-confirm on use.
4. Any output that leans on these MUST carry a `[provisional: scrape-dated, verify before commit]` tag.
