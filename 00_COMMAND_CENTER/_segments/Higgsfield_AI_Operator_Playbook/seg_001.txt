prompt-and-pray generation to controlled pipeline management. High-quality cinematic output requires a systemic workflow, not better prompts. Higgsfield consolidates character
creation, image generation, video animation, motion design, and monetization into one ecosystem. The operator advantage comes from treating it like a production studio: lock
identity first, build a reusable asset library, then animate with cinematic intention. Key Insights Features vs. Models is the core architecture. Features are the workflows (Cinema
Studio, Lipsync, Draw to Video, Click to Ad). Models are the engines (Kling 3.0, WAN 2.6, Seedance 2.0). Pick what you're making first, then pick what powers it. Character
consistency is the entire game. Train a Soul ID with 20-30 reference photos (varied angles, lighting). Without this, you're paying the 'AI inconsistency tax' every time you
regenerate. One image becomes nine shots. The Shots app generates 9 unique angles from a single master image. 1x credit, 9x output. Build this library before animating anything.
Prompt like a director, not a writer. Composition + Subject + Camera Move + Mood. One clear camera move looks more cinematic than stacked moves. Shot structure goes at the top of
every prompt. Number of shots, total duration, aspect ratio. Everything else follows. This is the difference between coherent output and random clips. Seedance formats are genre
recipes. Transformations (highest performing), Orbs (first-person POV), POVs, Fights, Animation. Each has a formula. Learn the formula, swap the content. Be explicit about what the
camera is NOT doing. 'No cuts, no zoom, natural head movement' keeps perspective locked. Without negative constraints, the model defaults to cutting between angles. Monetization is
built in. Higgsfield Earn pays for posted content. But the real money is in services: AI influencer management, brand kits, cinematic B-roll packs. 1. Platform Architecture 1.1

Pre-Production Define character: Train Soul ID (20-30 photos, varied angles/lighting) or build in AI Influencer Studio. Generate 5-10 master keyframes with Nano Banana Pro to
establish visual style. Create prop sheets for recurring objects: multi-angle orthographic views (front, side, back, top). Run all images through Skin Enhancer for consistent
texture. Build shot library: Run master images through Shots app (1 image = 9 angles). 2.2 Production Generate scene keyframes in Soul Cinema to establish per-scene visual style.
Edit characters into keyframes if needed (Nano Banana Pro for hair, outfit, feature swaps). Animate: feed keyframes + references into chosen model (Seedance for action, Kling for
dialogue, WAN for narrative). Apply Cinema Studio camera simulation: lens settings, dolly moves, depth of field. 2.3 Post-Production Review like an editor. Adjust one variable at a
time and regenerate. Upscale final clips. Export into editing workflow for captions, music, cuts, formatting. Store all assets in organized project folders. You will reuse them.
2.4 The Consistency System Character reference goes into every prompt. Tag explicitly: '@image_1 is the character reference' Style references are separate. Tag: '@image_2 is the
visual style reference ONLY' For multi-scene: feed previous scene's video as context for continuity Start Frame locks the look. End Frame locks a clean finish for
cuts/thumbnails/CTAs When editing characters, explicitly state what NOT to change: 'preserve lighting, environment, camera angle exactly as they are' 3. Prompt Architecture 3.1
Universal Prompt Structure Shot structure declaration: shots, duration, aspect ratio (always at top) Reference tags: identify every input and its role (character, style,
environment) Style declaration: aesthetic, rendering approach, film quality specs Timed segments: break duration into named blocks (0-3s, 3-6s) with specific action Camera
behavior: what camera IS doing and is NOT doing Negative constraints: 'no 3D, no cartoon' for realism; 'no cuts, no zoom' for locked POV Shot-level formula: Composition + Subject +
Camera Move + Mood. Example: 'Medium close-up, eye level. Subject turns slightly. Slow dolly-in. Soft cinematic lighting.' 3.2 Seedance Format Recipes Format What It Is Formula
Transformations Highest-performing format. Character transforms triggered by threat. Number each shot. Describe exact action. Escalation: calm > threat > transformation >
aftermath. 6 shots / 15s. Orbs Continuous POV. Camera IS character's eyes. Hyper-chaotic handheld. One shot, first-person, 15s. Use [VFX: description] brackets inline for power
visuals. POVs Locked first-person perspective for immersion. Explicit negative: 'no cuts, no zoom, natural head movement.' This keeps the perspective. Fights Choreographed combat
with clear escalation. Exact choreography beat by beat. Include slow-motion ramps: RAMPS TO SLOW MOTION / SNAPS BACK. Animation Stylized animated sequences with timed segments.
Break 15s into timed blocks. Keyframe as style reference. Describe physics as precisely as actions. 3.3 Pro Tips Realism: Add 'no 3D, no cartoon, no VFX' to force ultra-realistic
rendering. Comedy: 'Add a visual gag in the background' and Seedance invents one. Body VFX: Use brackets inline: [VFX: branching electric circuits pulsing with white-blue current].
Film quality block: 'Cinematic lighting, photorealistic, 35mm film quality, professional color grading, sharp focus, film grain, depth of field mastery, ARRI ALEXA aesthetic.'
Multi-scene continuity: Start every scene with 'Extend @video1. Continue exactly from the white flash of the last frame.' Sound design: Add SFX block at end listing specific sounds
in sequence. Seedance matches them to action. Sometimes short wins: 'Fight of a 3D person with 2D' produced viable animation with zero image input. 4. Multi-Scene Film Production
The method for maintaining narrative and visual consistency across scenes in different animation styles: Start with consistency assets: character keyframe + recurring prop sheet
(multi-angle views) before any scenes. Generate scene keyframes in Soul Cinema first. Each scene gets its own visual style established before animation. Edit keyframes to match
your character (Nano Banana Pro for swaps, preserving everything else). Animate with Seedance: keyframe + character ref + previous scene video as context. Use transition devices
(watch/portal/flash) for clean visual breaks between styles while keeping narrative continuity. Proven styles that work across scenes in a single film: 2D Anime, French Graphic
Novel/Moebius, Chibi Low-Poly, 3D Claymation, Black & White Manga, 2D Cartoon in Live Action, and Live-Action Cinematic. The character reference stays constant across all of them.
5. Vibe Motion (Motion Design) For projects needing precision: infographics, presentations, logo animations. Chat-based interface, not timelines. Choose format: presentation,
infographics, text animation, poster, or from scratch. Describe in chat + upload assets. System builds around your files, not placeholders. Apply template (optional). Templates
have complex motion logic baked in. Refine: click elements to adjust font, color, size, background. Adjust physics: speed slider for sharp/energetic vs smooth. 6. Monetization 6.1

Publish + Monetize: Post to Earn campaigns daily. Package workflow as client service. The Operating Principle The leverage is not in generating one good clip. It's in building a
library of consistent assets that compound. Every Soul ID trained, every shot library built, every prop sheet generated becomes reusable. One character, nine angles, five outfits,
three animation styles, twenty clips, a month of content. That's the gap between prompting and operating.
