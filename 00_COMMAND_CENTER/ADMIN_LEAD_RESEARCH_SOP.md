## 1. Admin mission
Build a clean, enriched target list of BASEPLATE's ideal buyers so BJ can start conversations the moment the internal system is tight. The admin fills the top of the funnel with research only. The admin never makes contact.

## 2. What admin is ALLOWED to do
- Build the target list (companies + decision-makers).
- Research and enrich each row (name, title, LinkedIn, verified email, location, segment, email provider).
- Tag urgency signals.
- Keep the CRM/sheet clean (dedupe, formatting, status).
- Enter proof-log data BJ dictates.
- Organize sample assets and files.

## 3. What admin is FORBIDDEN to do
- Contact, DM, email, call, or pitch anyone. Ever.
- Write outreach copy or creative.
- Make any offer, quote, or representation of BASEPLATE.
- Make creative, pricing, or strategy decisions.
- Use any employer (Serverfarm) data, lists, accounts, or inside knowledge.
- Touch any live conversation or reply.

## 4. Target segments
- **A. Critical-facilities staffing / recruiting firms (priority):** firms placing data-center / critical-facilities techs, commissioning agents, MEP roles. Size ~10-150. Decision-maker: owner, founder, president, VP recruiting, head of talent or employer brand.
- **B. Specialty subcontractors:** electrical, mechanical, commissioning, cooling, networking, field service, bidding into data-center / mission-critical projects. Size ~15-300. Decision-maker: owner, president, VP business development, preconstruction, estimator/proposal lead.
- Geo: LA/SoCal first, then Northern VA, Phoenix, Dallas, Atlanta, Columbus.

## 5. Exact lead fields (one row per firm)
Company · Decision-maker name · Title · LinkedIn URL · Verified email · Email provider (Gmail / Outlook / other) · Location · Segment (staffing / sub) · Urgency signal · Source · Notes.

## 6. Urgency-signal fields (tag at least one per row)
- Critical-facilities reqs posted 60+ days / reposted / aged.
- "Urgently hiring" or repeated reposts of the same role.
- Recent data-center project win or contract announcement.
- Active or upcoming bid / RFP.
- Headcount-growth posts or hiring sprees.
- A tired/thin careers page or capability statement (qualitative note).

## 7. Research sources
LinkedIn (company + people search, job posts), company websites/careers pages, Instantly Super Search export (BJ provides), public bid/RFP boards, trade directories and associations, verified-email lookup. Public information only.

## 8. Instantly / LinkedIn / manual research workflow
1. BJ runs Super Search with the Outbound Playbook §6 filters and hands the admin the raw export.
2. Admin verifies each company fits a segment (size, focus, geo).
3. Admin finds the decision-maker (not a generic inbox), grabs LinkedIn URL + verified email + email provider.
4. Admin tags the urgency signal and notes anything qualitative.
5. Admin dedupes and formats the row into the CRM/sheet.
6. Admin flags the strongest rows (clear decision-maker + named urgency) for BJ's first batch.
Admin uses LinkedIn to RESEARCH only, never to message.

## 9. Quality-control checklist (per row)
- [ ] Real decision-maker (no info@ / sales@).
- [ ] Verified email (not guessed).
- [ ] Email provider tagged.
- [ ] Segment correct.
- [ ] At least one urgency signal noted.
- [ ] Not a duplicate.
- [ ] Public-source only, no employer data.

## 10. Duplicate rules
One row per firm. Before adding, search the sheet by company and by decision-maker name. If the firm exists, update the existing row, do not create a second. Merge variants (LLC vs Inc, DBA names).

## 11. Employer-clean rules (hard)
- Never use Serverfarm data, lists, CRM, or inside knowledge.
- Never add Serverfarm's own clients, vendors, or employees to the list.
- Public sources only.
- Admin works on its own accounts and time, never employer systems.
- If unsure whether a target is connected to the employer, flag it to BJ and do not add it.

## 12. Daily deliverable
A set number of fully-enriched rows per day (BJ sets the quota, e.g. 8-10), plus CRM hygiene on any rows BJ touched. A short note of any strong rows worth BJ seeing first.

## 13. 48-hour deliverable
The first 25 staffing + 15 subs (40 rows total), fully enriched, deduped, urgency-tagged, with the strongest rows flagged. This is the first batch the warm/manual outreach (Phase 1) will draw from when BJ decides to go.

## 14. What gets escalated to BJ
- Any reply, inbound message, or contact attempt from a prospect (admin never answers; hand to BJ immediately).
- Any target possibly connected to the employer.
- Any ambiguity about segment fit, decision-maker, or whether a firm qualifies.
- Anything requiring a judgment, creative, pricing, or representation decision.

## 15. What admin never handles
Conversations, replies, pitches, offers, copy, creative, pricing, strategy, the proof-log interpretation (data entry only), the sample dossier creation, any client relationship, anything employer-related.
