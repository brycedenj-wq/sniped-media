## Install (not present anywhere; add when the input demands it)
4. After Effects , motion graphics + sound for real trailers. Path: install on Mac (you have Creative Cloud) + handoff via Desktop Commander, or render frames the OS composites. Trigger: cinematic trailer with animated titling. HIGHEST creative-ceiling install.
5. Premiere , long-form multi-track edit + audio. Path: same as AE. Trigger: a real edited film.
6. Blender , true 3D objects/sets/type. Path: brew install blender; drive via Python (Blender has a Python API = scriptable, unlike PS). Trigger: a 3D product drop or virtual set. The one 3D install that is actually scriptable into the OS.
7. Runway , alternative motion model. Path: subscribe; bridge via API. Trigger: a shot Seedance cannot do.
8. Spline , interactive 3D web. Path: install if an interactive 3D landing is wanted. Trigger: interactive web hero.
9. Unreal , virtual production. Path: year-2+. Trigger: real-time cinematic environments.

## Note on Blender
Blender is the highest-value INSTALL for range because it has a Python API , the OS could drive it headlessly (blender -b -P script.py) and gate the render, unlike Photoshop/Premiere which need GUI automation. If a 3D drop becomes the play, Blender wires into the OS more cleanly than any other missing tool.
