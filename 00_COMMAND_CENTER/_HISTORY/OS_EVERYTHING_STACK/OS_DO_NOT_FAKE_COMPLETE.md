# OS DO NOT FAKE COMPLETE , the anti-bullshit law
The OS must never fake-complete, skip proof, miss obvious layers, or call access capability. Hard rules:
- notes are NOT capability. access is NOT capability. installed is NOT active. connected is NOT active.
- plugin visibility is NOT workflow. read is NOT certified. generated is NOT produced. pretty is NOT shippable.
- template is NOT excellence. provisional doctrine is NOT truth. old lane is NOT destiny.
- one strong package is NOT the total ceiling. "optional" is NOT a dismissal. everything enters; the input routes.
A capability is ACTIVE only with ALL of: a callable route or handoff, an artifact, a log, a gate result, a dashboard update, and it repeats.
Before saying "done": name the artifact + the gate verdict + the log. If any is missing, it is not done , say what is missing.
