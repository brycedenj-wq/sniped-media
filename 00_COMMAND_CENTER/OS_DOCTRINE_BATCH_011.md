## DOCTRINE ENTRIES (deduped)

### D-01 · Phase-Gated Audience Engine
Three-stream Phase 1 only (LinkedIn POV 1x/week + IG Carousel 1x/week + Stories daily shoot-weeks). 90-120 min/week budget. Phase B fires when $3K/mo x 2 consecutive months + 5 Resets + first Op Kit pitched + cash reserve >$3K. Phase C fires after Phase B completions. No cultural doc carousel, Substack, BTS video, or separate Reels in Phase 1. Anti-pattern suppression is mandatory, not optional. IG grid curation to coherence starts Month 4. Carousel is primary IG format (5-8 frames). Stories cadence: daily during shoot-weeks, 0-3x/week off-season.

### D-02 · Multi-Output Pipeline (One Shoot, 5+ Outputs)
One shoot seeds: client gallery, portfolio pool, IG carousel, LinkedIn POV, Stories burst, plus conditional BTS video, cultural doc, Substack, case study, referral mechanism, partner content. Audience compounds through consistency + multi-output architecture, not volume. Five compounding loops: LinkedIn POV warms VIB conversion; Heroes grow portfolio driving Carrd conversion; Cultural doc builds referral trust over 6+ months; IG carousel drives profile visits to DM; Substack becomes owned audience asset Year 2+.

### D-03 · Five Visible Frame Markers + Three Caption Markers
Frame: color discipline, pose architecture, rim light, clinical retouch, graphic over atmospheric. Caption: protocol-named, deployment context, no sentimental fluff. Two carousel markers: cover earns swipe, close frames loop. All five markers in every published frame. "Instantly recognizable at thumbnail" is moat-level design.

### D-04 · Beat-First Video Editing + AI/Identity Boundary
Audio chosen before clip work. Markers map every beat/downbeat. Paper edit pre-specifies cut list. Clips laid to match markers with hard cuts on downbeats. AI motion permitted on environment, product, props, transitions only. Model identity (face, body) is always real footage. Hard rule: no AI identity. Two grade lanes: Lane A editorial (Old Hollywood warmth, film look) for the film itself; Lane B clean (color-true, web-clean) for product/web deliverables.

### D-05 · Dual-Lane Grading Doctrine (Lane A / Lane B)
Lane A editorial: 90s vacation warmth, cherry-red motif, film grain, lifted blacks, stylized color. Lane B clean product: color-accurate, neutral WB, modern contrast, no grain, tight framing. Skin is master: melanin-rich skin protection outranks stylistic moves. Grey/ashy/green renders are grading failures, not skin failures. Lane routing is deterministic once client confirms frame use. Color guardrail override: skin tone authority outranks mood. If cherry-red grade greens skin, grade is wrong and must roll back.

### D-06 · v3 LUXURY Lock (Adobe Neutral Base)
v3 LUXURY (Adobe Neutral + quiet luxury editorial restraint + HEX palette #2A2A2E/#B8956E/#C9B7A3/#F5EFE6) is canonical. All prior v1 (Adobe Portrait base) references are obsolete. No alt edits, no experimental branches. Three-tool pipeline: Lightroom (catalog, develop, masks) + Evoto (skin, body, backdrop, color match, advanced retouch) + Lightroom (hero finish, export). Photoshop reserved for Track B environmental compositing only.

### D-07 · Lightroom Operating System (LOS v3.0)
One master catalog per year (`SNIPED_YYYY.lrcat`). Five cull passes (Pass 0: AI auto-reject; Pass 1: manual X/P; Pass 2: star rating; Pass 3: color label; Pass 4: hero count check). Target: 15-25 min cull per Reset, 8-12 Heroes per Reset. Develop workflow: 10-step sequence (crop, WB, tone basic, presence, HSL, detail, lens/transform, effects, masking, final review). Masking stack: 5 AI masks per Hero in 60-90 sec via copy-paste propagation. Retouch decision tree: Q1 structurally clean? Q2 Generative Remove? Q3 skin needs AI retouch? Q4 Brand System tier? Time targets: Hero 12-15 min; Select 1-2 min; Proof 30-45 sec.

### D-08 · Color Label + Smart Collection System (Locked)
Color labels: Red = heavy retouch; Yellow = standard Evoto; Green = Hero candidate; Blue = VIB asset; Purple = case study. Star ratings: 5-star = Hero; 4-star = Select; 3-star = Proof. 13 locked Smart Collections (Heroes Live, Heroes Pending Retouch, VIB Pool, Case Study Pool, This Month, Last 90 Days, Selects, Proofs, Cultural Doc Heroes, Reset Deliveries, By Lens, Needs Photoshop). Manual collections per-shoot delivery named `YYYY-MM-DD_Client_TYPE`.

### D-09 · Export Preset Hierarchy (9 Locked Presets)
Hero JPG (Quality 90, no resize), TIF Master (16-bit ProPhoto), Selects (Quality 85), Proofs (Quality 80, resized 2400px), IG Carousel (1080x1350), LinkedIn POV (same), Carrd (2000px long edge), Press (full quality + metadata), VIB Asset (per SOP format). Each writes to preset-defined subfolder. Never export watermarked, sub-1080px, AdobeRGB web, or Smart Preview-only.

### D-10 · Preset Library Architecture
5 develop presets: Locked Look (applied on import), Hero Finish (post-Evoto), Proof Batch, Cultural Doc (Eterna/Classic Chrome profile + stronger contrast), B&W Editorial (film grain amount 25 size 30 + stronger S-curve). 1 metadata preset (SNIPED_COPYRIGHT_2026, IPTC, annual variant). 1 import preset (chains locked-look + copyright). Per-image refinement is not invention: exposure, contrast, saturation, masks, crop are editorial choice within locked foundation. Build once, backup as .xmp, quarterly dry-run, never delete (disable instead).

### D-11 · Evoto Corrected Scope (8 Capabilities)
Evoto is primary backdrop tool for studio register. Frequency separation + sculpt dodge/burn moved from Photoshop to Evoto for Brand System tier. Photoshop routing: Track B environmental compositing only. Eight capabilities: color match, backdrop optimization, perspective/horizon correction, frequency separation, dodge/burn sculpting, AI culling (tethered sessions only), tethered shooting (Phase B+ trigger), cloud sync. Ten forbidden features: hair color change, skin tone shift, smile generation, eye color, makeup application, tattoo removal, uncrop, open eyes, expression changer, body reshape. Rule: anything that changes who the model IS (not how the photo READS) is off the table.

### D-12 · Three-Tool Pipeline + Retouch Decision Tree
Lightroom is spine. Evoto is skin specialist. Photoshop is surgeon. AI is assistant. Most frames live entirely in Lightroom. Some travel to Evoto. Few visit Photoshop. None get generated. Resets never see Photoshop. Brand System tier (Q4 yes) unlocks full pipeline including Photoshop. Decision tree: Q1 structurally clean? Q2 Generative Remove handled? Q3 skin needs AI retouch? Q4 Brand System tier frame?

### D-13 · Photoshop Ceiling Doctrine
Photoshop is a ceiling tool, not a general editor. Solves only what Lightroom, Evoto, Adobe MCP, Firefly web, and Higgsfield cannot finish. Ten core techniques by priority tier. Tier 1 (close immediately): compositing (4) > skin retouch + D/B (2) > Generative Fill discipline (5). Tier 2 (after tier 1): advanced masking (1) > Smart Objects (9) > Camera Raw Smart Filter (3) > color matching (6). Tier 3 (lane-activated): print master (7), actions batch (8), generative prompt (10). Every tutorial must produce at least one persistent OS asset. Conversion rule: raw notes archive; the asset is the leverage.

### D-14 · Generative Fill Reject Gate
Quality below original = don't use. Reject gate is non-negotiable. Enhancor.ai forbidden until AI subjects are adopted (they won't be). Firefly is utility on real photographs (post-capture cleanup only): three approved use cases (generative fill for backgrounds, remove-people for venue shoots, text-to-template for layouts). Berger rule absolute: AI never produces the delivered photograph, never replaces founder presence, never replaces Direction Stack methodology.

### D-15 · Photoshop Wave 1 Proof-by-Doing Gate
0 of 7 technique proofs complete as of 2026-05-30 lock. Proof-by-doing precedes SOP hardening. All proofs downstream of next active SNIPED shoot or composite work. Phase 2 gate: BJ approves ONE technique to SOP first (recommended: Generative Fill, most recent failure mode). Write SOP, apply to one real image, iterate, then decide next SOP or gap acquisition.

### D-16 · 7-Environment Composite Rotation (Locked 2026-05-12)
Recognizable visual authorship comes from consistent world-building, not novelty-chasing. One environment per chapter. Subjects rotate through it. Seven environments: Brutalist Monument (5/5 escalation, hero escalation), Industrial Minimal (3/5, chapter bridge), Monochromatic Void (4/5, identity portrait), Sculptural Gallery (3/5, artifact/legacy), Cinematic Urban (4/5, operator-coded), Organic Surreal (3/5, creative/fashion), Futurist Editorial (5/5, rare 1-2x/year max). Subject identity (face, hair, body, skin tone, proportions) stays exactly as photographed. Background replacement only, never subject regeneration. Path A default: Photoshop Generative Fill with reference image. Path B better register: external AI plate + Photoshop composite.

### D-17 · Year-Long Environment Pacing
Q1: Brutalist + Cinematic Urban. Q2: Industrial Minimal + Monochromatic Void. Q3: Sculptural Gallery + Organic Surreal. Q4: Brutalist (second, year-end escalation) + Futurist Editorial (rare). Eight chapters across the year using all 7 environments. Technical specs: PNG export for AI input (sRGB, 8-bit, 2048px long edge). Same color architecture (#B8956E skin retention) across all 7.

### D-18 · Track B Compositing Workflow (Gress Playbook)
Five-step playbook: studio capture + Lightroom + Evoto light pass + AI background plate + Photoshop assembly. Plate quality check is non-negotiable gate: if plate direction fails, regenerate before opening Photoshop. Do not try to fix wrong-direction plate in Photoshop. Harmonize Neural Filter: start at 50%, scale to 60-75% per WB mismatch severity. Color wash opacity ceiling: 3-7% max. Edge light sampled from plate brightest highlight. Unifying grain + color wash + vignette are unifying layers, not effects stacking. Quality gate Step 7: fix ONE thing, not five. Ship at good enough; frame 2 will be better. After frame 5 the house style locks. 36-finals target is the live training set.

### D-19 · Physics-First QA Gate (Composite Master QA, Locked 2026-06-02)
Workflow-technically-working does NOT equal a pass. Required: proof crops (100% hair, 100% feet) + per-hero QA scorecard (lighting, grounding, edge/hair, color marry, artifact, brand fit; each /10). No QA score = cannot go to client. Subject grade is read-only: TIFF + PNG cutout is locked. Compositing work is environment integration only. Clear acrylic physics failure pattern documented: requires true-sole detection through acrylic, silhouette-base contact shadow, anchored cast, warm acrylic transmission + reflection. ~90% ceiling before human Photoshop heel hand-finish.

### D-20 · Platform Mastering Law (Locked 2026-06-02)
A hero is finished when its platform masters pass (color + B&W per aspect per safe-area, contrast/sharpen/text applied), NOT when the composite passes. Color leads; B&W is one prestige sidecar only. Flagship-first deck architecture: build strongest hero to client-ready first, then secondary worlds rebuild. Secondary worlds rebuild internally only until they pass the same 6-axis scorecard.

### D-21 · Deck Architecture (Flagship-First)
Alma Love instance locked: BH pool (client-ready v2) anchors deck. WEST + BEACH rebuild internally until they pass the QA scorecard. Color over B&W as lead asset (B&W flattens the pink BH Hotel palette). B&W is editorial prestige sidecar only. Red car focus control: car may steal focus from swimsuit; must be controlled. Ranch world only ships if pushed to intentional cowgirl-glam aesthetic.

### D-22 · 9-Master Edit Vocabulary (Edit Moves From the Greats)
Avedon / Eggleston / Leibovitz / Shore / Herzog / Frank / Meyerowitz / Haas / Iturbide. Finished image = 2-4 moves combined, never all nine. Pipeline: ingest raw, pick lane, apply moves in order (tone curve, HSL, color grading, masks, texture/grain, retouch), audit (10+ point improvement = working combination). Five spine truths: restraint over push; color discipline before composition; light direction matters more than quantity; texture is integrity not decoration; retouch protects subject, doesn't replace them. Quiet editorial lane = Shore / Meyerowitz / Eggleston / Leibovitz weighted, NOT Frank / Haas / Herzog.

### D-23 · Master-to-Environment Mapping
Brutalist Monument = Shore. Industrial Minimal = Eggleston. Monochromatic Void = Iturbide. Other four environments TBD per environment assignment. Each composite environment now has a master assignment. Preset library ships as 9 named presets (one per master), not a "luxury" catch-all.

### D-24 · Reset Capture-to-Delivery SOP (5-Day SLA)
Phase 1: same-day triple-backup (laptop/SSD/Drive), file-count verification, SD card formatted in-camera only. Phase 2: v3 5-pass cull (15-25 min). Phase 3: 3-tier edit pipeline (8-12 Heroes + 30-40 Selects + 60-100 Proofs in 2-3.5 hr). Phase 4: export + Pixieset (20 in Selections, 10-15 in Additional at $80/image, 14-day expiry, 48-hr upsell window, no watermark, gallery tested incognito). Phase 5: Day 5 delivery at 9:00 AM PT. Phase 6: cleanup + Notion card update. Failure modes: >90-min cull = force 4-pass discipline; edit >15 min/image = capture problem not post fix; SLA miss = communicate ASAP.

### D-25 · Three-Tier Edit Pipeline (v2 Override, Live 2026-05-06)
AI cull + tiered editing replaces the old "20 fully retouched" model. Output: 8-12 Heroes + 30-40 Selects + 60-100 Proofs in 2-3.5 hr per Reset. v1 (20 images, 3.5-5 hr) is deprecated. Edit floor rules: Lightroom base (WB by skin tone, protect subject highlights, HSL lock-block tighten), Evoto retouch (clinical not plastic, grain on background only), Photoshop only when needed (frequency separation, compositing, liquify, backdrop). Most Resets skip Photoshop.

**C-01 · Evoto vs Photoshop scope (RESOLVED in this batch)**
Old LOS v3.0 and PRODUCTION_OS stated "Photoshop ONLY: frequency separation, dodge-and-burn." **C-02 · Grain application rule (minor)**
The preset library and v3 LUXURY docs specify subtle global grain applied in Hero Finish (amount 12, size 25, roughness 50, "only visible at 100% zoom"). The legacy OS v1 craft discoveries doc specifies "no-global-grain rule: grain applied only to background mask, not globally." These are in direct tension.
Resolution: The v3 LUXURY locked preset is authoritative (2026-05-12 lock supersedes v1). The no-global-grain rule is a v1-era constraint that was resolved in the preset build. Grain in Hero Finish at amount 12 is the canonical behavior. The legacy note should be understood as pre-v3 constraint.

**C-03 · Lightroom dual-lane preset distillation vs LOS single-lane distillation**
The `02_dual_grade_system.md` distillation describes Lane A (editorial) using "Adobe Color" as baseline and Lane B (clean product) using "Adobe Neutral" as baseline. The LOS v3.0 specifies Adobe Neutral as the universal foundation for the locked-look preset. The Alma Love instance has two downstream lanes, but the capture-time foundation is one preset.
Resolution: There is no true conflict. The LOS single locked-look (Adobe Neutral) is the import baseline for all captures. Lane A vs Lane B divergence happens in the develop workflow layer (tone curve choices, HSL moves) after the locked foundation is applied, not at the profile selection step. The dual-grade distillation's "Adobe Color for Lane A" refers to where the editorial character comes from (color profile choices within the develop panel), not a separate import preset. This is a framing ambiguity, not a doctrine contradiction.

**C-04 · Track B primary tools (Firefly legacy path flagged as backup)**
Track B Frame Walkthrough explicitly states: "UPDATED 2026-05-12 onward: Primary tools are now Higgsfield Soul, Seedream 5.0, Nano Banana Pro. Firefly A/B/C options are now backup/reference only." The UDEMY AI Tactical Extraction (USE NOW item 3) lists "Adobe Firefly utilities" and the Photoshop Ceiling Curriculum lists Firefly-based generative fill as Path A default in the composite environment rotation. These appear to list Firefly as primary.
Resolution: The distinction is by use case. Firefly (via Photoshop Generative Fill with reference image) is Path A DEFAULT for background generation within Photoshop compositing. Higgsfield/Seedream/Nano Banana Pro are Path B (better register) for external plate generation. The Track B Frame Walkthrough's "backup" language refers specifically to the older Firefly direct-prompt method (without reference image). The two paths coexist. No contradiction; the Firefly-as-primary-direct-prompt path is deprecated, but Firefly inside Photoshop GF workflow remains Path A.
