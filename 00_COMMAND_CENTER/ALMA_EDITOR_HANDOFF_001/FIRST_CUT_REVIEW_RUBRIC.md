# First-Cut Review Rubric - Alma Love reel

Score the editor's first cut against this BEFORE accepting. Based on Commercial Craft Benchmark V2 (beauty/fashion reel profile) + os-vision-reject-gate. 9/10 is the floor. If it is not 10, name the exact blocker and the fix.

## Watch it twice: once with sound, once MUTED.

## Pass/fail gates (any fail = send back, not a vibe)
- [ ] **Reads muted.** The story/feeling lands with sound off.
- [ ] **Hero is the longest clean hold.** There is one clear hero beat and it is held longer than the rest. (If every shot is the same length, FAIL = stitch feeling.)
- [ ] **Motivated cuts only.** Every cut is on a beat or a motion. No random cuts, no template bounce/zoom.
- [ ] **Consistent grade.** One look across all shots. No clip that jumps in color/exposure.
- [ ] **No slop frames.** No soft/blurry/awkward/blown clips made the cut (os-vision-reject-gate).
- [ ] **Brand-true.** Feels like Alma (warm retro Americana), not a generic swimwear edit.
- [ ] **Identity consistent.** Same model reads across every shot.
- [ ] **Length 30-45s, vertical 9:16.**

## 12-axis quick score (0-3 each; target >= 30/36, no axis at 0-1)
hook_strength, shot_variety, subject_continuity, audio_motivates_cuts, transition_logic, pacing_contrast (hero longest), visual_hierarchy, typography (if any, restrained), payoff (the hero), commercial_clarity (brand reads), rewatch_value, premium_feel.

## The one question
Does it look expensive, or does it look like stitched clips? If stitched: the usual cause is uniform shot lengths, no held hero, or inconsistent grade. Name which one and send it back with that single note.

## Verdict options
SEND BACK (one note) / ACCEPT as proof / ACCEPT sendable. Do not accept a 6 or 7. A 9 with a named path to 10 is acceptable for a $60 first cut; below 9, one revision.
