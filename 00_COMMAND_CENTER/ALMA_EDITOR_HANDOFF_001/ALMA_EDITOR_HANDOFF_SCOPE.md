# Alma Love - Editor Handoff Scope (conductor run, 2026-06-08)

Emergency mode, $60 scope, ONE deliverable. The handoff to the editor is simple. The thinking behind it used the whole OS. This doc is internal (the editor gets only `EDITOR_MESSAGE.md` + the two rubrics). Mode: EMERGENCY (scope cut) + MAX taste (quality not cut).

## The deliverable (locked, do not expand)
**One 30 to 45 second vertical (9:16) Alma Love reel.** One cut. Not three. No YouTube version. No alt edits. No template pack.

## 1. Full OS scan (what fired)
- Domain: film/video (hard). Mode: EMERGENCY + SERIOUS -> MAX taste.
- Active: cinema-worldbuilder (shot grammar/sequence), os-world-bible (Alma world rules), os-vision-reject-gate (kill weak frames), watch (clips must be WATCHED not sampled), os-face-lock (model identity consistent across clips).
- Reference consulted: COMMERCIAL_CRAFT_BENCHMARK_V2 (beauty/fashion reel profile), OS_FINISHING_DEPARTMENT_STANDARD (MODE B visual selects; never edit source in place; selects -> rough cut), OS_AUTOEDIT_DOCTRINE (selects -> beat grid -> rough cut), platform-mastering (9:16 export), sniped-caption-writer (only if a text beat is needed).
- Cross-domain pulled: brand_campaign (Alma world: warm retro Americana, western/beach/soda-shop, red signature, cards/dice club, group/plural energy) so the reel feels like Alma not generic; writing/status-psychology (the emotional read); qa_proofing (vision-reject + 12-axis + watch on every chosen clip).
- Toolchain: Premiere (cut), the locked Alma grade/LUT (do not regrade from scratch), no AE template ceremony.
- Asset reality: ~380 raw clips (Canon D94A* + iPhone IMG_*) in `ALMA_LOVE_PRODUCTION_001/01_RAW_VIDEO`. Prior V4/V5 cuts existed and read as cheap stitched TikTok. That is the failure we are preventing.

## 2-3. Emergency scope decision + the ONE excellent thing
- **The one excellent thing:** the HERO LOOK held. One sustained, confident, beautifully-graded beat of the model in the Alma world that the whole reel builds to and rests on. Per beauty/fashion craft: the hero look is the LONGEST clean frame. That single beat is what makes it read expensive instead of stitched.
- Everything else serves that beat.

## 4. What gets CUT (emergency)
Second/third videos. 16:9 cut. Template transitions. Motion-graphics title ceremony. Regrade-from-scratch (use the locked Alma grade). Filler clips. More than one revision pass in this $60 scope. Heavy captions.

## 5. What NEVER gets cut (quality floor)
Brand taste + the locked Alma grade. Model identity consistency across clips (os-face-lock). Clip quality (no soft, blurry, awkward, blown-out frames). The held hero. Beat-sync. Motivated cuts only (the anti-stitch rule). Honest labeling.

## 6. Sequence shape (tight, not a stitch)
Hook (<1.5s, one striking frame, pull the eye) -> build (2-4 motivated beats: motion + texture inserts intercut) -> HERO held (the longest clean beat) -> button (one closing frame / logo-or-wordmark moment). Cut to the track. ASL roughly 1.0 to 4.5s with the hero as the long hold. No uniform same-length cuts (that is what makes it feel like a stitch).

## 7. Why this is not a TikTok stitch (the named fix)
Stitch feeling comes from: uniform shot lengths, unmotivated cuts/zooms, inconsistent grade, no held hero, template transitions. We forbid all five: motivated cuts only, one consistent locked grade, pacing CONTRAST (hero is the long hold), no templates, beat-synced.

## 8. Gates (first cut must pass before it is "done")
os-vision-reject-gate on every shipped frame (no slop), Commercial Craft 12-axis (beauty/fashion profile) >= 30/36, reads MUTED, hero held longest, consistent grade, brand-true. 9/10 floor; if not 10, name the blocker.
