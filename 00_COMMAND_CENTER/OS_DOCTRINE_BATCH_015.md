**D-03 · Reference Intake Template (all ceiling modules)**
Per source: title + author + platform + URL + date consumed + 3-5 key takeaways + rejected patterns found + distillation linkage (checklist.md or reject_gates.md). This is the single canonical intake format across all 10 photoshop_ceiling_v1 modules.

**D-04 · Checklist Population Protocol**
Tutorial consumed → step-by-step distillation (tool + shortcut + value + panel toggle + zoom level) → strip anti-patterns → apply to 2-3 real SNIPED frames → refine → lock. Checklists replace tutorial re-watching. Reject gate per checklist: observable failure mode triggers revert and retry.

**D-05 · Sent DM Artifact Discipline**
Every drafted DM (LinkedIn, IG, email) is saved as a file at draft time, not send time. File naming: `YYYY-MM-DD_recipient-handle.md`. Required fields: recipient details, platform, draft date, send date, status (drafted/sent/replied/dead/converted), verbatim message copy, reply received, result. No DM leaves without an artifact on disk.

**D-06 · Pair-DM Cadence for Co-Founder Outreach**
Both co-founders receive outreach within 48 hours on slightly different positioning (one: press/launch announce; one: operational/founder-spotlight presence). 48-hour stagger prevents "coordinated" read. Apply to YC-cohort, hardware-launch, and other co-founder clusters.

**D-07 · Visual Protocol Gap as Outreach Hook**
Outreach to founders uses frame-comparison method: left (current state visual) vs right (SNIPED reference) to surface the visual protocol gap without shame or critique language. "Protocol diagnosis from photo" gate must complete before DM ships (protocol number selected, not generic template). Applies to all warm-tier and Tier 0 founder outreach.

**D-08 · Post-Pipeline Grade Lane System**
Two lane types, locked: Lane A (Editorial/Content: IG grid/story/campaign; drives video matching) and Lane B (Website/Product: e-commerce/product pages). Cull-time color-label tagging routes each select to correct lane. Batch preset applies at GATE. Heroes receive manual finish on top of lane base. Identity untouched across both lanes per edit register bifurcation doctrine.

**D-09 · Batch Automation Threshold (Lightroom handoff)**
Batch ops are pre-flight cleanup only. Lightroom-level masking (skin/product/background isolation) is the actual creative decision point, not batch recipes. Preset spec 07 (Lightroom) is the handoff threshold. Clients should expect Lightroom masking precision on hero/key frames, batch uniform treatment on non-hero selects only.

**D-10 · Post-Pipeline Proof-First Protocol**

**D-11 · Brief Template (8-field gate + 3 manual review points)**
