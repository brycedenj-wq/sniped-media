## Enforcement
- `os_premium_stack_gate.py plan <task>` before stage 1.
- Build the stack. Justify any skip in writing.
- `os_premium_stack_gate.py audit <task> --used ... --justified ...` after.
- `os_elite_art_direction_gate.py score ...` must read STRONG minimum, ELITE target.
- A run is MAX only when both gates pass (or skips are justified) and underuse is logged.

## Spend posture
Premium-on within the authorized run budget. Spend that materially raises quality is correct. Conserving credits at the cost of quality is a failure. Refill when the work justifies it.
