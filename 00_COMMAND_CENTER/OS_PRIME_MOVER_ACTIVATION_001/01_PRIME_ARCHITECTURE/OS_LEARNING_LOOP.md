# OS LEARNING LOOP , every output makes the OS sharper
1. CAPTURE , every gate FLAG/FAIL + every shipped artifact is logged with its verdict.
2. CLASSIFY , failure -> {mechanical | taste | tool | safety | capability}. Success -> the recipe that worked.
3. RULE , a failure becomes a line in OS_NEXT_TIME_RULES (Rn). A success becomes a doctrine/recipe addition.
4. FUSE BACK , the rule/recipe is wired into the module's doctrine or gate so the lesson is enforced, not remembered.
5. PROVE , the next run cannot repeat the caught failure (the gate now blocks it).
Examples already fused: F2 world-copy bleed -> R2 (no hard-coded world copy) -> world copy blocks. F4 param shadow -> R4. Weak copy -> os_doctrine gate. The loop is the reason "no more surprise missing layers" becomes true over time.
