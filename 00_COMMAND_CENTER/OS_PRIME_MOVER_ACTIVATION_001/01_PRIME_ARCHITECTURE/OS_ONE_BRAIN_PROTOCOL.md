# OS ONE BRAIN PROTOCOL , the contract every action follows
For ANY input, the OS (or any agent/workflow acting as the OS) MUST:
1. ROUTE , os_prime_router maps input -> modules. Name the modules awake.
2. FUSE , for each module, os_doctrine load <domain>. Inject the doctrine BEFORE creating.
3. EXECUTE , route the module's tools (USE_NOW first; HANDOFF/WIRE flagged with steps).
4. GATE , run the module's gates (production/motion/privacy/doctrine/blender). No artifact passes ungated.
5. SELF-CORRECT , if a gate FLAGs: auto-fix what is mechanical, regenerate with the doctrine pack for what is taste, or mark honestly FAILED. Never ship "good enough."
6. LOG , EDIT_LOG + the right ledger (Higgsfield tank / Adobe tank) + gate log.
7. DASHBOARD , update the run's status surface.
8. LEARN , any failure -> failure ledger -> a next-time rule so it never recurs.
This is what makes the OS one brain instead of separate drawers. It is wired for copy in os_engine; agents apply it for the model-judged domains.
