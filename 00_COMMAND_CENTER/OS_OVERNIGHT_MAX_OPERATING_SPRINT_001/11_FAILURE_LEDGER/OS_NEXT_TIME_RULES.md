# OS NEXT-TIME RULES , hard rules that prevent recurrence
R1. Never call Adobe image tools on a non-whitelisted URL. Upload to Adobe storage first, or use the local equivalent.
R2. No layout/render function may hard-code world copy. All world text flows from the world JSON via the engine.
R3. Legal risk stays flagged (low_legal_risk=0) until a real legal pass. Never auto-clear it.
R4. Never reuse a parameter name as a local variable; treat shadowing as a bug.
R5. Inventory the LIVE session for callable tools before any run. Mark installed-not-bridged as AMBER with a handoff, never ACTIVE.
R6. Generate 1k to gate, 4K only winners. Kill weak concepts before spending on stills.
R7. Taste-gate checks default PENDING; never auto-SHIP an asset no human/model has seen.
R8. Every credit logged (tool, model, purpose, cost, in, out, verdict, advanced-mission) before the next spend.
R9. Stop on any public/identity/employer/legal/payment/irreversible action. Document, never perform.
R10. A capability counts only with a proving artifact (route/execute/produce/gate/log/export/repeat).
