## A. Naming strategy
The bottleneck is structural, not creative: **there is no clean, unclaimed, premium one-word name left.** Every pronounceable coinage we generated and checked already has an incumbent somewhere. So the decision is not "find a free name" , it is choosing on three axes: (1) **idea/sound fit** to the brief, (2) an **acquirable address** (bare premium .com is dead; use `.house`/`.studio` or a coined compound), and (3) **cross-class trademark headroom** (a same-name incumbent in a DIFFERENT Nice class is coexistable; a design/marketing-adjacent incumbent is not). Target the suggestive/invented lanes in the engraved-nameplate sound register, wrap in a HOUSE suffix, and clear with counsel before any public use.
