## SOLE risk verdict: KILL as public-facing name
- "Sole" is a common dictionary word (fish, shoe sole, sole proprietor). `solehouse.com`, `thesolehouse.com`, `sole.house` all TAKEN. Trademark field crowded across many classes. Verbal/visual fine, but ownership and search-distinctiveness are lost.
- **Keep SOLE only as the internal codename** for this proof so file names and prior docs do not churn. Do not use publicly.

## Hard reality this gate surfaced
Every pronounceable, premium single word with a free bare `.com` is gone. All 20 bare coinages checked were taken (sovra, onora, solum, onliq, soliter, unato, onum, soveren, solenne, vantrel, onoris, soluxe, sovrene, onlea ...). And the three best-sounding ones each have a real incumbent:
- **SOVRA** , mdf commerce / KKR public-procurement SaaS (2024 rebrand, owns sovra.com). Unrelated class.
- **ONORA** , registered USPTO mark (Onora Global LLC, TM 90006358) + premium home brand "Onora Casa". Category-adjacent (premium/design).
- **SOLUM** , large global retail-tech brand (Samsung Electro-Mechanics spin-off, 35+ countries). Unrelated class.

Conclusion: a same-name incumbent in a DIFFERENT trademark class is now the norm, not a dealbreaker. The realistic premium play is a distinctive word + the on-brand `.house` TLD (which literally names the entity), with formal trademark clearance in the services classes (likely 35 / 42) before lock.
