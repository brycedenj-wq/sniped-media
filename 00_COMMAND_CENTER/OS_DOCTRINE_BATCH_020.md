## MASTER-DOCTRINE ADDITIONS

The following doctrine items emerge from this batch that are not already fully expressed in existing memory docs and warrant addition or explicit reinforcement:

1. **The 5-class constraint taxonomy (A-E)** is the router's gatekeeping logic. Class A (hard) is the only refusal. Classes B-E route with modifiers. This taxonomy operationalizes the difference between "cannot do" and "do with style." Currently lives in COMMAND_ROUTER.md and MASTER_OS_SYNTHESIS.md. 2. **Session health metrics are measurable.** "Sessions produce more file writes than file reads" is a health indicator, not a vague goal. Governor tracks: stale standing order, audit-mode default, proof loops within caps. These are binary pass/fail checks, not subjective grades. Add explicit health-check pass/fail logic to EXECUTION_GOVERNOR.md if not already present.

3. **Hospitality compounds separately from service.** The hospitality layer is not a quality-of-service upgrade; it is a reputation-compounding mechanism that operates above the delivery SOP. Every client touchpoint has a service layer and a hospitality layer. Budget-neutral hospitality moves have outsized status-signaling effects with founder-buyers (per intel_status_psychology).

4. **Taken vs made distinction is the theoretical spine of the anti-AI moat.** Berger's insight (appearance without maker = image without authorship) is the strongest theoretical defense of SNIPED's positioning. This is not decorative philosophy; it is positioning ammunition. Every AI defense argument should run through this frame before publishing.

5. **Input classification precedes STANDING_ORDER load.** The command router corrected this order in 2026-05-29. It is a fundamental protocol change: do not assume what the user wants based on standing order; classify the input type first, then route. This distinction prevents the governor from treating every input as a task when it may be a state signal, a relationship move, or a raw material.

## CONTRADICTIONS FLAGGED

1. **Composite lane routing vs daily practice ambiguity.** Hero Ceiling is explicitly refused for "daily IG posts" and Hero Lite is specified as the IG creative engine. However, no skill explicitly defines the cadence boundary for what qualifies as "portfolio anchor" vs "strong IG post." A frame could reasonably be routed either way without a clear tiebreaker rule. Recommendation: define a tier-threshold test (print intent, book inclusion, pitch deck use, or sustained campaign anchor = Ceiling; everything else = Lite).

2. **Evoto backdrop replacement scope vs composite environment rotation.** Evoto allows backdrop replacement within "same studio register only." The composite environment rotation defines 7 environments (Brutalist Monument, Industrial Minimal, etc.), most of which are NOT studio environments. These two doctrines are potentially in conflict when a frame starts in studio and the desired rotation environment is non-studio. Evoto is not the right tool for out-of-register environment changes; that routes to composite (Ceiling or Lite). The routing decision tree in the retouch SOP should make this explicit.

3. **Input-first routing vs session-start standing order announcement.** The command router was corrected to classify input before loading STANDING_ORDER. However, the execution governor's session-start behavior requires announcing the standing order within 10 seconds before input arrives. These are sequential not contradictory (governor announces on session open, router classifies when first input arrives), but they can read as contradictory if both are invoked simultaneously. The resolution is: governor's session-start is a one-time cold-start behavior; router's input-first rule governs all subsequent inputs in the session. This should be stated explicitly in both skills.

4. **Lean audit quarterly cadence vs overcommitment signal triggers.** The lean audit is described as "quarterly" but also triggered by "I'm feeling overwhelmed" or consideration of new surfaces. If BJ is overcommitted month 1, waiting for a quarterly audit is too slow. The skill's trigger condition should be clarified as "quarterly minimum, immediately on any overcommitment signal."

5. **sniped-photo-theory's Dyer citation.** The skill attributes the "captions are non-optional" insight to Dyer and the "photograph ambiguity demands them" framing. The loaded intel_photo_theory.md is attributed to Berger and Dyer together but the specific "Ambiguity of the Photograph" essay is a Berger essay, not Dyer. Dyer's primary contribution is the ambiguity-as-interpretive-gap idea in "The Ongoing Moment." This conflation is minor but could cause mis-citation in the Direction Stack book preamble. Recommend re-reading BOTH sources before any published methodology framing cites them.
