## 0. LOCKED IDENTITY SPINE (every asset inherits this. Do not re-describe per-prompt, reference it.)

**HARD IDENTITY LOCK (4-pillar, faceless-safe) [CERT os_crs harness]:** Eye geometry, face geometry, build, complexion are gate inputs but the **face is never the hero of any frame**. Identity is carried below the chin and at the wrist. Face appears only as: lost profile, downward 3/4 cropped at the brow, back-of-head, or blurred behind a numbered portrait-glass. The face is structurally withheld in 11 of 12 stills.

**SOFT SIGNATURE (the ownable tell) [CERT os_crs + one soft mark]:**
- The **kraft paper LOT 00 auction tag on string**, knotted at her right wrist. Always present. The single most-repeated object in the universe.
- The **single riding glove, held in the left hand, never worn.**
- The **portrait-sitter stance:** spine vertical, chin level, hands clasped low and forward.

**WORLD STAGE (constrained rotation that COMPOUNDS, run AS DESIGNED) [CERT composite_environment_rotation]:** Four estate rooms, one per chapter, never mixed inside a frame:
1. **TACK ROOM** (auction-tagged saddles on iron racks) → maps to Industrial Minimal slot, bridging chapters.
2. **PORTRAIT GALLERY** (every frame wears a lot number) → maps to Sculptural Gallery slot, legacy/artifact chapters.
3. **EMPTY STABLE** (one horse-shaped absence in the straw) → maps to Monochromatic Void slot, identity heroes.
4. **GRAND STAIR** (crated furniture stacked to the ceiling) → maps to Brutalist Monument slot, hero escalation.

**COLOR-LAW (non-negotiable literacy) [PROV status lens + CERT visual_direction]:** Everything renders in Adobe-Neutral quiet-luxury restraint, sub-8 saturation, lifted creamy blacks, rolled highlights, no teal/orange. **The ONLY saturated element permitted anywhere is auction-red, and it is allowed ONLY on lot-tag string and stamp.** Red = "this is for sale." If red touches a non-sale object, the frame is rejected on sight.

**DUAL-REGISTER [CERT bw_card_dual_register]:** HERO frames = color (the estate still hers). CARD frames = B&W (the lot SOLD). Apparatus/masthead stays color.

**THE PUNCTUM RULE [PROV photo canon, Barthes]:** Every hero frame carries ONE unplanned, refused-to-clean wound: a thread pulled on the glove, the tag string frayed, a saddle billet cracked, one fingernail catching light wrong, dust in a single shaft. On the do-not-clean list. The smoothing instinct of the model is overridden by spec.

**SCALE-VIOLENCE RULE [CERT diagnosis: conflict makes a frame alive]:** The figure is always dwarfed, hemmed, or crowded by crated/stacked lots. She is never centered and comfortable. She is in conflict with the room, never decorating it.

**APPARATUS / NOEME [CERT entertainment room + PROV noeme]:** Every unit carries the slug `LOT 00 / [ESTATE NAME] / [YYYY-MM-DD]` in auction-house ledger serif, an edition stamp, and a re-attribution short-code so it survives being clipped.

**Envelope discipline:** stills target ~2cr (single GPT Image 2 / Nano Banana Pro plate, identity conditioned on locked hero ref, not text). Clips target ~18cr (Seedance, single locked shot, minimal motion). Nothing in this plan requires a multi-shot clip.

## 9. THE NEW REJECT GATE (pointed at FORGETTABLE, not just inconsistent) [CERT strongest_photograph reject gate]

Before any unit ships, it must pass all five. The machine already knows how to refuse itself on a failed mole. This points that refusal at the only test not on the QA sheet:

1. **ICON TEST:** Is the LOT 00 tag present and is the frame recognizable cropped to a thumbnail with the face removed? If no → reject.
2. **STANCE TEST:** Does it advance the fight (lineage is not untouchable; even the bloodline is for sale)? If it's neutral/decorative → reject.
