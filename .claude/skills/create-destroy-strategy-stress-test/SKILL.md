# Create-Destroy Strategy Stress Test

**Skill ID:** 1.3  
**Category:** Strategy & Competitive Analysis  
**Source Document(s):** STRATEGIC_THINKING_FRAMEWORKS.docx

## Purpose

Overcome premature cognitive closure by systematically generating, attacking, and rebuilding strategy alternatives until a robust survivor emerges.

## When to Use

When developing, evaluating, or stress-testing business strategy. When a team needs to move from vague ambition to concrete, coordinated action.

## Instructions

Follow this workflow precisely. Each step is grounded in the source document(s) listed above. Do not skip steps. Do not invent frameworks, models, or terminology not present in the source material. Execute each step in order, using the exact logic and decision criteria documented.

## Workflow

1. Generate an initial strategy using the Kernel framework (Diagnosis + Guiding Policy + Coherent Action).
2. Destroy it: Systematically attack the strategy. Identify weaknesses, wrong assumptions, and what a smart competitor would do to defeat it.
3. Invoke a virtual panel of experts: Ask each mental-model persona what is wrong with the approach.
4. Create a new alternative: The new strategy must address the weaknesses exposed, not be a trivial tweak. It should flow from a genuinely different diagnosis.
5. Repeat the create-destroy cycle at least 2-3 times. Each round should produce higher-quality alternatives.
6. Evaluate the survivors: Compare strategies that survived destruction. Choose the most robust one with the fewest fatal vulnerabilities.

## Output Format

Produce all of the following deliverables:

- A documented progression of strategy versions (V1 through final)
- A vulnerability register for each version
- The surviving strategy with rationale for why it is most robust
- A risk watch-list of remaining vulnerabilities to monitor
