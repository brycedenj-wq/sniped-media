# Superforecasting Workflow

**Skill ID:** 2.3  
**Category:** Decision-Making & Forecasting  
**Source Document(s):** SUPERFORECASTING_FRAMEWORKS.docx, Prediction_Forecasting_Systems_FRAMEWORKS.docx

## Purpose

Apply the five-phase forecasting methodology used by top performers in the Good Judgment Project to produce calibrated probability estimates for business-critical questions.

## When to Use

When you need a calibrated probability estimate for a business-critical question.

## Instructions

Follow this workflow precisely. Each step is grounded in the source document(s) listed above. Do not skip steps. Do not invent frameworks, models, or terminology not present in the source material. Execute each step in order, using the exact logic and decision criteria documented.

## Workflow

1. Triage: Classify the question as clocklike (use simple heuristics), Goldilocks zone (apply full methodology), or cloud-like (stay near 50%, don't waste effort).
2. Fermi-ize: Decompose the question into sub-questions. Separate knowable from unknowable components. Expose all assumptions.
3. Establish the Outside View: Find the reference class. What is the base rate for events of this type? Set this as your starting probability anchor.
4. Investigate the Inside View: Conduct targeted, hypothesis-driven research on case-specific factors. Apply dialectical reasoning (for each argument, generate the strongest counterargument).
5. Integrate Perspectives (Dragonfly Eye): Consult diverse sources. Generate your own second opinion. Synthesize into a single probability estimate using weighted judgment.
6. Express as a granular probability: Use single percentage points where skill supports it.
7. Set up monitoring: Create information feeds specific to the question. Update frequently with small incremental adjustments (average 3-5 percentage points per update).
8. Conduct a postmortem after resolution: Analyze both successes and failures. Separate skill from luck. Document transferable lessons.

## Output Format

Produce all of the following deliverables:

- A granular probability estimate (single percentage points)
- A documented reasoning chain showing outside view anchor, inside view adjustments, and perspective integration
- An update log tracking belief revisions over time
- A postmortem analysis (after resolution)

User provides context about their specific situation. The skill guides them through each workflow step sequentially, producing all deliverables listed in the Output Format section. Each step builds on the previous one, and no step should be skipped.
