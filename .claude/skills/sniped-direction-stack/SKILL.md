# SNIPED Direction Stack Skill

The methodology diagnostic. Output target: 5 calibrated answers that drive every shot list / pose / wardrobe / light decision.

## MANDATORY READING

1. `/Users/sniper/Downloads/    SNIPED_OS/08_BOOK/` · Direction Stack book outline (if exists)
2. `/Users/sniper/Downloads/    SNIPED_OS/00_BRIEF/OPERATIONAL_BACKBONE.md` Section 2 · what BJ owns forever (Direction Stack diagnostic is #1)
3. `/Users/sniper/Downloads/    SNIPED_OS/05_PRODUCTION/SOP_reset_shoot_day.md` · where it runs on shoot day

## INVOKE WHEN
- Pre-shoot prep (the diagnostic is run in pre-shoot intake)
- Discovery call (the diagnostic is the conversation)
- Client doesn't know what they want (run the diagnostic to find out)
- "What should this shoot look like"
- Direction Stack book chapter work

## THE 5 QUESTIONS (the locked diagnostic)
The 5 questions per the locked methodology. Each one calibrates a different dimension of the final output. (Specific question text lives in the Direction Stack book chapters · this skill orchestrates which to ask and how to surface the answer.)

## OUTPUT
- The 5 calibrated answers for this specific client / shoot
- The chapter / mood / register the answers point to
- Wardrobe / pose / light implications

## REFUSE
- Skipping the diagnostic (it's the methodology)
- Doing the diagnostic as a checklist (it's a conversation)
- Letting the client over-prescribe before the diagnostic completes


## Inputs
- Client name and session type (Reset / Op Kit / Brand System)
- Any prior intake notes, VIB one-pager data, or discovery call transcript if available
- Context for when in the workflow this is running: pre-shoot prep / discovery call / shoot day reset

## Gates
- Diagnostic must run as a conversation, not a checklist dump: all 5 questions must be surfaced interactively
- Client cannot over-prescribe before the diagnostic completes: their framing is held until all 5 answers are in
- Diagnostic cannot be skipped even if the client says they already know what they want: it is the methodology moat
- No shot list or wardrobe/light/pose output until all 5 calibrated answers are produced
