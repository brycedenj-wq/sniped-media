# Hoshin Kanri Goal Alignment System

**Skill ID:** 18.2  
**Category:** Operational Excellence (Toyota Way)  
**Source Document(s):** OPERATIONAL_EXCELLENCE_FRAMEWORKS.docx

## Purpose

Align organizational improvement energy from strategic vision to daily execution using the Hoshin Kanri (policy deployment) system with catchball negotiation and A3 thinking.

## When to Use

When preparing for or conducting any high-stakes negotiation involving pricing, contracts, partnerships, or resource allocation.

## Instructions

Follow this workflow precisely. Each step is grounded in the source document(s) listed above. Do not skip steps. Do not invent frameworks, models, or terminology not present in the source material. Execute each step in order, using the exact logic and decision criteria documented.

## Workflow

1. Define True North: The organization's ideal long-term state (not achievable, but provides direction).
2. Set 3-5 breakthrough objectives (3-5 year horizon): The must-achieve goals that close the biggest gaps between current reality and True North.
3. Cascade to annual objectives: What must be accomplished this year to make progress on breakthrough objectives? Make them specific and measurable.
4. Conduct catchball: Iterate between levels. Senior leadership proposes targets; middle management proposes means and counter-proposes what is feasible. Iterate until alignment is reached.
5. Document each objective on an A3: Background, current condition, target condition, root cause analysis, countermeasures, implementation plan, and follow-up on a single page.
6. Establish regular review cycles: Monthly or quarterly reviews comparing actual progress to plan. Gaps trigger root cause analysis, not blame.
7. Connect to daily management: Standardized work, visual management boards, andon response systems, and daily PDCA at the team level.

## Output Format

Produce all of the following deliverables:

- A True North statement with 3-5 breakthrough objectives
- Annual objectives aligned via catchball negotiation
- A3 documents for each major objective
- Review cadence with gap-analysis protocol

User provides context about their specific situation. The skill guides them through each workflow step sequentially, producing all deliverables listed in the Output Format section. Each step builds on the previous one, and no step should be skipped.
