# Meta Business Infrastructure Setup

**Skill ID:** 13.1  
**Category:** Meta Platform & Commerce  
**Source Document(s):** Meta_Business_Infrastructure_Framework.docx

## Purpose

Set up the complete Meta business ecosystem (Business Suite, Commerce Manager, CRM, cross-platform distribution) in the correct sequence to prevent bans and fragmentation.

## When to Use

When a persistent problem resists repeated fix attempts, suggesting the issue is structural rather than personnel-based.

## Instructions

Follow this workflow precisely. Each step is grounded in the source document(s) listed above. Do not skip steps. Do not invent frameworks, models, or terminology not present in the source material. Execute each step in order, using the exact logic and decision criteria documented.

## Workflow

1. Verify personal Facebook profile with government ID first. Select highest verification tier. Enable two-factor authentication.
2. Create Business Portfolio (formerly Business Manager) in Meta Business Suite.
3. Connect Facebook Pages, Instagram accounts, WhatsApp, ad accounts, and pixels under one management interface.
4. Set up Commerce Manager: Create product catalog that feeds both Facebook Shop and Instagram Shopping.
5. Configure the Unified Inbox: Aggregate Messenger, Instagram DMs, WhatsApp, Facebook comments, and Instagram comments.
6. Set up the built-in CRM: Label contacts, tag as leads, move through customizable pipeline (Intake > Qualified > In Progress > Converted).
7. Configure cross-platform content distribution: Set up the Planner calendar for simultaneous publishing with platform-specific customization.
8. Assign team member permissions with proper security levels.

## Output Format

Produce all of the following deliverables:

- Verified and secured Meta Business Suite account
- Commerce Manager with populated product catalog
- Unified inbox with CRM pipeline configured
- Content distribution calendar across all Meta platforms

User provides context about their specific situation. The skill guides them through each workflow step sequentially, producing all deliverables listed in the Output Format section. Each step builds on the previous one, and no step should be skipped.
