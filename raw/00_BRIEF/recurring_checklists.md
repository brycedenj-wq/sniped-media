# Recurring Checklists · daily / weekly / monthly / quarterly

The operating cadence as deployable checklists. Print each once, tape to the wall, run.

---

## DAILY · 15-30 min · executed in your morning or afternoon energy peak

- [ ] Open Notion · scan `Operator Dashboard` (top of CRM)
- [ ] Reply to any client/prospect DM under 24h (LinkedIn, IG, Gmail)
- [ ] Move any Pipeline cards that need a status update from yesterday's actions
- [ ] Check `Active SLA` view: is anything close to the 5-day delivery clock?
- [ ] Check `Active 48h windows` (Galleries): is an upsell window closing today?
- [ ] **Protected Hour:** one of {VIB production · Direction Stack POV draft · edit pass · contract/template work} · phone in another room · selected the night before · 60% on bad days, never zero

**If traveling for engineering:** skip Protected Hour without guilt. The daily Notion check still happens (5 min on the laptop in the hotel).

---

## WEEKLY · Monday AM · 30 min review + plan

### Review (15 min)
- [ ] Log the week's metrics in the Notion Dashboard:
  - VIBs sent (target: 3+)
  - Discovery calls held (target: 1+)
  - Cash collected (running 4-week tally)
  - Edit hours actual (vs. moving average)
  - Studio utilization hours
- [ ] Review last week's `Stale` Pipeline cards · either send a follow-up Loom OR move to `Re-engage 90d`
- [ ] Review `Day-30 Op Kit pitch trigger` view · pitch any Reset clients now at the 30-day mark
- [ ] Review `Closed windows · revenue tally` · capture upsell revenue from the prior week

### Plan (15 min)
- [ ] Identify 3 LA founder targets for this week's VIBs · save URLs to `/03_OUTREACH/queue/YYYY-MM-DD/`
- [ ] Confirm shoot calendar for the week · pre-shoot briefs scheduled for 24h before each shoot
- [ ] Schedule this week's LinkedIn POV post (Tue or Thu, 7-9 AM PT) · pull from `/07_CONTENT/linkedin_pov_bank.md`
- [ ] Identify the **single Constraint** for the week (the bottleneck the next 7 days will fix)
- [ ] Set Next action dates on every active Pipeline card

### Tonight (Monday evening · 25 min)
- [ ] Protected Hour: produce 3 VIBs per `SOP_VIB_production.md`
- [ ] Queue DMs to send Tue/Wed/Thu

## MONTHLY · last Monday of the month · 60-90 min

### Constraint Audit (30 min · Revenue Stack Part IX)
- [ ] List every current initiative (paid shoots, free shoots, outreach, content, build tasks)
- [ ] Rank by impact on revenue (not by effort)
- [ ] Identify the **single constraint** that, if cleared, unlocks 3+ other problems
- [ ] Kill everything else for the next 30 days · explicitly authorize lower-priority fires to burn

### Numbers review (20 min)
- [ ] Revenue: month-over-month tally · running 90-day forecast vs actual
- [ ] Pipeline: count of `Reset Booked` + `Op Kit Booked` cards · estimated value of `Forecast` view
- [ ] Conversion: VIBs sent / Discovery calls / Resets booked → conversion % at each step
- [ ] Bottleneck check: edit hours per shoot moving average · is it climbing?
- [ ] Free-shoot ledger: each category producing the named return?

### Content + portfolio review (15 min)
- [ ] Last month's LinkedIn POVs ranked by engagement · which 3 worked best · why
- [ ] Last month's shoots: which produced a hero image worth adding to the Carrd Selected Work?
- [ ] Update Carrd if a stronger frame replaces a current Selected Work entry

### Mirror Test (10 min)
- [ ] Zoom out 10 years · is the next 30 days moving toward the life you actually want?
- [ ] Identify any decision in the upcoming month that fails the Mirror Test · kill it

---

## QUARTERLY · first Monday of each quarter · 90 min

### TAM refresh (45 min)
- [ ] Re-segment the LA founder list based on what triggered replies vs what didn't
- [ ] Move `Re-engage 90d` cards back into active rotation if their situation changed (new role, funding, post)
- [ ] Add a fresh batch of 30-50 new targets to the Notion Outreach DB · score by trigger count
- [ ] Each card gets a fresh trigger angle · the same prospect doesn't re-receive the same script

### Offer ladder review (20 min)
- [ ] Reset: still $1,500? Booked-out 3 weeks? Time to raise to $1,800-2,000?
- [ ] Op Kit: any graduated to Op Kit this quarter? Pricing band still right ($3-5K early)?
- [ ] Brand System: is the 3-Op-Kit threshold met? If yes, draft the first Brand System pitch
- [ ] Strategic free: each category producing returns? Pause any that aren't

### Aesthetic v-bump (15 min)
- [ ] Review the last 5-10 shoots against the Aesthetic Statement v1
- [ ] Update v1 if signatures have evolved (new texture, new color discipline, new pose vocabulary)
- [ ] Save as v2 in `/00_BRIEF/aesthetic_statement_v2.md` · keep v1 archived

### Three-pillar audit (10 min)
- [ ] Are the 3 Direction Stack content pillars (Craft / Business-Operator / Process-Personality) still balanced?
- [ ] Are LinkedIn POVs over-indexed on Craft (likely default)?
- [ ] Identify the next quarter's content emphasis based on the gap

---

## ANNUALLY · December → early January · 3-4 hour deep review

### The full Constraint Audit at scale
- [ ] Re-read the Operating Brief · note what's still true and what isn't
- [ ] Re-read the spine memory file · update if positioning has evolved
- [ ] Review the 4 Wealth Levels (Survival / Stability / Growth / Freedom) · which level is the business at?
- [ ] Review the niche-of-one position · still LA founders? Or has a sub-niche emerged?

### Hire decision review
- [ ] Has the year's revenue pattern justified a part-time retoucher?
- [ ] If yes, trial-hire one in Q1
- [ ] If no, defer the decision another quarter

### Public Direction Stack book launch (if Q3 already happened)
- [ ] Review the launch sequence's actual conversion
- [ ] Plan the digital-product layer for Year 2 (PDF + video course)

### Year 2 forecast
- [ ] Set Q1, Q2, Q3, Q4 revenue targets based on Year 1 actuals
- [ ] Identify the single most leveraged initiative for the year ahead

## Field-engineer travel mode (occasional, 1-2x/month)

When you're flying out Monday and back Friday for engineering work:

**Before flight (Monday AM, 30 min):**
- [ ] Run the Weekly Review · Plan section
- [ ] Pre-queue the week's 3 VIBs (sends scheduled in LinkedIn or via reminder)
- [ ] Pre-schedule the week's LinkedIn POV post (use Buffer or LinkedIn's native scheduler)
- [ ] Pre-write the auto-replies for any active Pixieset upsell windows that close during the trip

**On the road:**
- [ ] Daily Notion check (5 min) · only respond to client-facing items
- [ ] No new shoot bookings while traveling
- [ ] Editing on the road is acceptable IF the laptop + hard drive came along
- [ ] Skip Protected Hour without guilt

**Return:**
- [ ] Full Weekly Review the Monday after return (catch-up)
- [ ] Move stale cards · re-engage anything that went silent during travel
