## 4. Environment direction · Evoto backdrop swap (Path B)

**Decision:** Execute via Evoto backdrop replacement with color blend mode. NOT a full Rejuar composite. The red original lighting blends through, the new color/backdrop replaces hue/saturation while preserving studio lighting cues.

**Why this beats a full composite for CH02:**
- 2-look chapter doesn't justify Rejuar's bandwidth on a heavy composite.
- Color blend mode preserves the studio lighting Mimi was actually lit with · no relight mismatch risk.
- BJ retains full execution speed in Evoto.
- Detailed backdrop imagery (gallery walls, marble) would get washed out by color blend anyway · solid or muted is the correct call.

### Evoto backdrop options (pick one per look, or unify across both)

**Option A · Plaster warm gray (Sculptural Gallery register)**
- Backdrop color: `#BEB8AE` · rgb(190, 184, 174)
- Blend mode: Color
- Read: warm gray gallery plaster · brown wardrobe pops as warmest element. Closest to the locked Sculptural Gallery environment without doing the actual composite.

**Option B · Cool taupe (Monochromatic Void register)**
- Backdrop color: `#9A9590` · rgb(154, 149, 144)
- Blend mode: Color
- Read: neutral void · pulls toward locked v3 LUXURY palette mid (#C9B7A3 reference). Cleaner, more anonymous.

**Option C · Deep oxblood (keep the moody saturation)**
- Backdrop color: `#4A2A28` · rgb(74, 42, 40)
- Blend mode: Color
- Read: shifts the red from terracotta studio to oxblood luxury. Editorial moody. Bridges the original capture without erasing it.

**Recommended for CH02:** Option A (plaster warm gray) for HERO + build frames. Option C (oxblood) considered if you want CH02 to read as the "saturated mono studio" register and save Option A for a later chapter.
