# Sent DMs · Artifact Tracking

Every LinkedIn / IG / email DM drafted in any session gets saved here as it's drafted.

## File naming
`YYYY-MM-DD_recipient-handle.md`

Example: `2026-05-12_alice-founder.md`

## File template
```markdown
# DM to [Name] · [Platform]

**Recipient:** [name, handle, role, company]
**Platform:** LinkedIn / IG / Email
**Drafted:** YYYY-MM-DD
**Sent:** YYYY-MM-DD or "pending"
**Status:** drafted / sent / replied / dead / converted

## Context
[Why this person, what triggered the outreach, what intel informs the angle]

## The DM as sent
[Verbatim copy of what got sent]

## Reply (when known)
[Their response · paste verbatim]

## Result
[What happened · meeting booked / no reply / not interested / hired]
```

## Why this folder exists
Past sessions drafted DMs that vanished when sessions closed or cloud agents disconnected. Without artifacts on disk, results conversations are impossible. This folder makes outreach continuity persistent.
