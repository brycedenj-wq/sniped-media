# VIB caption + DM script library

Parameterized templates. Bracketed placeholders are the only thing that changes per send.

## Part 1 · Caption blocks (per protocol)

Use these as the caption text on the VIB Figma file. Pick the protocol that matches the dominant failure in the prospect's photo.

### Protocol 01 · Claw Hands
**LEFT:**
```
PROTOCOL: 01 · CLAW HANDS
OBSERVATION: Fingers spread, tension visible at the knuckles.
DEPLOYMENT IMPACT: Reads as anxious on investor materials.
```
**RIGHT:**
```
PROTOCOL: 01 · CLAW HANDS
OBSERVATION: Fingers loosened, hands given a defined task.
DEPLOYMENT IMPACT: Reads as composed on a press cycle.
```

### Protocol 02 · Locked Shoulders
**LEFT:** `Shoulders elevated and braced toward the camera. // Reads as defensive on an "About" page.`
**RIGHT:** `Shoulders dropped and rotated 12° from camera plane. // Reads as confident on a deck.`

### Protocol 03 · Squared to Camera
**LEFT:** `Body fully square to the lens, no rotation. // Reads as flat in a corporate gallery.`
**RIGHT:** `Body rotated 35° off-axis, weight on one leg. // Reads as deliberate in a board room.`

### Protocol 04 · Pinned Arms
**LEFT:** `Arms pinned to the torso, no negative space. // Reads as small on a podcast intro.`
**RIGHT:** `Arms separated from the body, defined silhouette. // Reads as commanding on a feature.`

### Protocol 05 · Soft Jawline
**LEFT:** `Chin pulled back, jawline collapses into the neck. // Reads as uncertain on a thumbnail.`
**RIGHT:** `Chin pushed forward and down, jawline defined. // Reads as decisive on a magazine cover.`

### Protocol 06 · Spinal Collapse
**LEFT:** `Upper spine rounded forward, chest closed off. // Reads as fatigued on team pages.`
**RIGHT:** `Spine extended, chest open, neck long. // Reads as authoritative on a keynote frame.`

### Protocol 07 · Forced Smile / Emotional Disconnection
**LEFT:** `Smile is mechanical, eyes don't follow. // Reads as performative on a profile.`
**RIGHT:** `Eyes commit before the smile arrives. // Reads as warm and earned.`

### Protocol 08 · Transition Freeze
**LEFT:** `Subject caught between poses, energy locked. // Reads as awkward on candid press.`
**RIGHT:** `Subject moving through the moment, frame caught the in-between. // Reads as alive.`

### Protocol 09 · Good Mechanics, Zero Presence
**LEFT:** `Pose is technically correct, no internal commitment. // Reads as a stock photo of a founder.`
**RIGHT:** `Mechanics held, eyes engaged with the lens. // Reads as the actual operator.`

### Protocol 10 · Full Psychological Shutdown
**LEFT:** `Subject's face has gone blank, retreated from the lens. // Reads as absent on the most important asset.`
**RIGHT:** `Subject re-engaged, present, on this side of the camera. // Reads as the founder showing up.`

## Part 2 · DM scripts (under 80 words)

The DM is sent on LinkedIn to the prospect immediately after the VIB image is uploaded. **One image, one message, no follow-up DM in the same thread for 5 days.**

### Script A · Cold, no trigger event
```
Hey [First name],

Pulled together a quick frame comparison for you. Left is your current LinkedIn photo. Right is a reference from a recent SNIPED Media session. The protocol diagnostic is the same on both sides · your photo reads as [Protocol N · Name], which shows up specifically on [LinkedIn / your press / your deck / podcast covers].

Worth a 10-min conversation if the gap looks worth closing.

· BJ
```
Word count: ~70.

### Script B · Cold, with trigger event (recent post / funding / role change)
```
Hey [First name],

Saw your [post about X / Series B announcement / new role at Y] and pulled a frame comparison for the visual side of that moment. Left is your LinkedIn photo. Right is a SNIPED reference. The protocol · [Protocol N · Name] · is the gap that shows up most on [the press cycle / the deck investors will see / the LinkedIn post that announces this].

10 min if useful.

· BJ
```
Word count: ~75.

### Script C · Tier 0 trigger (event in <14 days)
**Send Loom-only with the VIB as the on-screen visual.**

Loom (60–90 sec) script:
```
Hey [First name], BJ from Sniped Media.

Saw [event in 14 days] is on the calendar. Pulled a frame comparison.

[Show VIB on screen.]

Left is your current LinkedIn photo. Right is a reference from a recent session. The protocol · [Protocol N · Name] · is the specific gap. On [event-related deployment context: press, livestream thumbnail, post-event coverage], that gap is what reads first.

If you want a frame in the right register before [event date], I have a [day] window. The Reset session is 45 minutes, one location, twenty retouched in five business days. Reply here and I'll send the booking link.

· BJ
```

### Script D · Loom variant for non-trigger (rare, for high-value prospects who didn't reply to Script A)
Use only after Script A has gone unanswered for 7 days AND the prospect is high-priority.

Loom (60 sec) script:
```
Hey [First name] · BJ following up on the frame I sent. Wanted to add 30 seconds of context.

[Show VIB on screen.]

The reason I sent this rather than asking for a call cold: the diagnostic is the offer. If [Protocol N · Name] reads as the gap on your end too, the conversation is worth having. If it doesn't, no follow-up.

Either way, the comparison stands. · BJ
```

Create new Outreach card for the colleague with `Trigger: Referral`. Send Script A (cold, no trigger) but mention the referrer in line 1: `[Referrer name] suggested I reach out to you about your visual operating level on LinkedIn.`

## Part 4 · Pacing

- **6 VIBs per week** (Lean Audit override · v1 spec said 3 · math to $3K/month requires 6). Mon eve production for the week's queue, Tue/Wed/Thu sends · roughly 2 per send day. Never on Fri (low LinkedIn engagement) or weekends (low B2B engagement).
- **Each thread:** Day 0 send. Day 5 if no reply, Script D Loom. Day 10 if no reply, leave the thread alone. Move card to `Re-engage 90d`. Do not send a 3rd message in the same thread; sender reputation in their inbox is the point.
- **Maximum 1 send per prospect per quarter.** TAM refresh every 90 days; if the prospect's situation changes (new role, funding, post), they re-enter the rotation with a fresh trigger.
