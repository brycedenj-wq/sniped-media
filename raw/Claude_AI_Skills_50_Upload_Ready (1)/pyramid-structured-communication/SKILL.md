# Pyramid-Structured Communication (SCQA)

**Skill ID:** 5.2  
**Category:** Communication & Messaging  
**Source Document(s):** STRUCTURED_COMMUNICATION_FRAMEWORKS.docx

## Purpose

Structure any business communication (memo, presentation, email, report) using the Pyramid Principle's top-down logic and SCQA introduction framework.

## When to Use

When crafting any business communication that needs to be clear, memorable, and drive action.

## Instructions

Follow this workflow precisely. Each step is grounded in the source document(s) listed above. Do not skip steps. Do not invent frameworks, models, or terminology not present in the source material. Execute each step in order, using the exact logic and decision criteria documented.

## Workflow

1. Define the governing thought: What is the single main point the reader should take away?
2. Build the SCQA introduction: Situation (shared reality the reader agrees with) > Complication (what has changed or gone wrong) > Question (the question this triggers) > Answer (your governing thought).
3. Group supporting arguments at the Key Line level. Each must be the same kind of idea (describable by a single plural noun).
4. Order supporting arguments logically: deductive (premise > premise > conclusion), time-based, structural, or by degree.
5. For each Key Line argument, add supporting detail one level below. Each detail must directly support its parent point.
6. Apply the vertical test: Does every point raise a logical question (Why? How?) answered by the points below it?
7. Apply the horizontal test: Are all points at the same level truly the same kind of idea? Can they be labeled with one plural noun?
8. Apply the Plural Noun Test to every grouping. If you cannot find one plural noun covering all items, restructure.

## Output Format

Produce all of the following deliverables:

- A pyramid-structured document with governing thought at top
- An SCQA introduction paragraph
- Logically ordered Key Line arguments with supporting detail
- A document that passes vertical, horizontal, and plural-noun tests
