# System Analysis & Intervention Design

**Skill ID:** 3.1  
**Category:** Systems Thinking & Analysis  
**Source Document(s):** Thinking_in_Systems_FRAMEWORKS.docx

## Purpose

Diagnose persistent business problems by mapping system structure (stocks, flows, feedback loops), identifying leverage points, detecting system traps, and designing effective interventions.

## When to Use

When a persistent problem resists repeated fix attempts, suggesting the issue is structural rather than personnel-based.

## Instructions

Follow this workflow precisely. Each step is grounded in the source document(s) listed above. Do not skip steps. Do not invent frameworks, models, or terminology not present in the source material. Execute each step in order, using the exact logic and decision criteria documented.

## Workflow

1. Get the beat of the system: Watch how it behaves before disturbing it. Study history. Make time graphs of actual data.
2. Expose mental models: Write down your assumptions about the system. Make them explicit and testable.
3. Identify stocks and flows: What is accumulating or being depleted? What increases or decreases it?
4. Map feedback loops: Trace each flow to its decision rule. Classify each loop as balancing (goal-seeking) or reinforcing (amplifying).
5. Identify delays: How long between a change in stock and its effect on flow? Match intervention speed to system speed.
6. Determine loop dominance: Which loops are currently strongest? Which will dominate as conditions change?
7. Scan for system traps (archetypes): Check for Policy Resistance, Tragedy of the Commons, Drift to Low Performance, Escalation, Success to the Successful, Shifting the Burden, Rule Beating, Seeking the Wrong Goal.
8. Find leverage points using the 12-point hierarchy: Resist starting with parameters (#12). Look first at goals (#3), information flows (#6), and rules (#5).
9. Design the intervention: Test direction (counterintuitive?), look for side effects (trace causal chain 3+ steps), respect delays, preserve resilience.

## Output Format

Produce all of the following deliverables:

- A system map showing stocks, flows, and feedback loops
- Identified system traps with corresponding escape routes
- Leverage point analysis ranked by effectiveness
- Intervention recommendation with side-effect analysis and resilience check
