# Second Brain Setup & Operation (CODE + PARA)

**Skill ID:** 8.1  
**Category:** Knowledge Management  
**Source Document(s):** PKM_Systems_FRAMEWORKS.docx

## Purpose

Build and maintain a personal knowledge management system using the CODE method (Capture, Organize, Distill, Express) and PARA organizational structure (Projects, Areas, Resources, Archives).

## When to Use

When a persistent problem resists repeated fix attempts, suggesting the issue is structural rather than personnel-based.

## Instructions

Follow this workflow precisely. Each step is grounded in the source document(s) listed above. Do not skip steps. Do not invent frameworks, models, or terminology not present in the source material. Execute each step in order, using the exact logic and decision criteria documented.

## Workflow

1. Choose a digital notes app. Start with what you already have.
2. Create four top-level PARA folders: Projects, Areas, Resources, Archives.
3. Archive everything old into an 'Archive [Date]' folder. Start fresh.
4. Begin capturing: 2-3 notes per day. Capture what resonates using the four criteria: Inspiring, Useful, Personal, or Surprising.
5. Organize by actionability: Place each note by asking: Which project will this serve? > Which area? > Which resource? > Archives.
6. Distill on demand using Progressive Summarization: Layer 1 (captured excerpts) > Layer 2 (bold main points) > Layer 3 (highlight essentials) > Layer 4 (executive summary in your own words). Only distill when preparing to use a note.
7. Express by assembling Intermediate Packets into deliverables. Share early and gather feedback.
8. Run the Weekly Review: Clear inbox, review active projects, check calendar, reprioritize tasks, move completed items to archives.
9. Run Project Kickoff Checklist for new projects: Capture current thinking, review related folders, search for related terms, move relevant notes, create an outline.
10. Run Project Completion Checklist: Mark complete, celebrate, move reusable IPs to areas/resources, archive the project folder.

## Output Format

Produce all of the following deliverables:

- A functioning PARA folder structure across all digital platforms
- A capture habit producing 2-3 notes daily
- Progressively summarized notes ready for rapid retrieval
- A weekly review cadence maintaining system health
