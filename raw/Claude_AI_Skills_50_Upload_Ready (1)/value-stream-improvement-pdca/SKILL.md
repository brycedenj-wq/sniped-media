# Value Stream Improvement (Toyota Way PDCA)

**Skill ID:** 18.1  
**Category:** Operational Excellence (Toyota Way)  
**Source Document(s):** OPERATIONAL_EXCELLENCE_FRAMEWORKS.docx

## Purpose

Map, diagnose, and improve any business process using value stream mapping, eight-waste elimination, and iterative PDCA (Plan-Do-Check-Act) cycles based on the Toyota Production System.

## When to Use

When a persistent problem resists repeated fix attempts, suggesting the issue is structural rather than personnel-based.

## Instructions

Follow this workflow precisely. Each step is grounded in the source document(s) listed above. Do not skip steps. Do not invent frameworks, models, or terminology not present in the source material. Execute each step in order, using the exact logic and decision criteria documented.

## Workflow

1. Map the current state: Walk the actual process. Document every step, inventory point, information flow, and timeline. Use value stream mapping.
2. Identify waste using all three types: Muda (8 wastes: overproduction, waiting, transport, over-processing, inventory, motion, defects, unused creativity), Muri (overburden causing breakdowns/burnout), Mura (unevenness causing peaks and troughs).
3. Design the future state: Envision ideal flow with one-piece flow, pull systems, leveled production, built-in quality, and visual management.
4. Create an implementation plan: Break the gap between current and future state into achievable improvement loops.
5. Execute through PDCA: (1) Grasp current condition by direct observation (go and see), (2) Define specific target condition, (3) Identify obstacles, (4) Plan one small experiment, (5) Do the experiment, (6) Check results against prediction, (7) Act on what you learned.
6. Stabilize and standardize: Update the standard when improvements are verified. Train all team members.
7. Repeat: The future state just achieved becomes the new current state. Begin the next cycle immediately.

## Output Format

Produce all of the following deliverables:

- A current-state value stream map
- A waste audit (muda, muri, mura categorized)
- A future-state value stream map
- A PDCA experiment log tracking improvements and learnings
- Updated standardized work documentation
