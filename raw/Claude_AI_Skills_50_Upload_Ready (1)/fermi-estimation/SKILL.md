# Fermi Estimation

**Skill ID:** 2.4  
**Category:** Decision-Making & Forecasting  
**Source Document(s):** SUPERFORECASTING_FRAMEWORKS.docx

## Purpose

Break seemingly impossible-to-answer questions into smaller, estimable components to produce surprisingly accurate approximations for business sizing, competitive intelligence, and strategic planning.

## When to Use

When evaluating business operations, financial structure, or revenue growth opportunities.

## Instructions

Follow this workflow precisely. Each step is grounded in the source document(s) listed above. Do not skip steps. Do not invent frameworks, models, or terminology not present in the source material. Execute each step in order, using the exact logic and decision criteria documented.

## Workflow

1. Decompose the question: Identify the knowable and unknowable components.
2. Flush out assumptions: Make every implicit assumption explicit. Write them down.
3. Estimate each component: Use available data, base rates, or educated guesses for each sub-problem.
4. Combine estimates: Multiply, add, or integrate component estimates into an overall answer.
5. Sanity-check the result: Does the answer pass a gut check? If wildly off, revisit assumptions.
6. Document the estimation chain so others can audit and refine the assumptions.

## Output Format

Produce all of the following deliverables:

- A decomposition tree showing each sub-question and its estimate
- An overall estimate with confidence range
- A list of assumptions ranked by sensitivity (which assumptions, if wrong, would change the answer most)
