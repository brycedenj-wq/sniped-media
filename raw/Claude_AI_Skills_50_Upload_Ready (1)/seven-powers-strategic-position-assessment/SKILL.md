# 7 Powers Strategic Position Assessment

**Skill ID:** 1.4  
**Category:** Strategy & Competitive Analysis  
**Source Document(s):** 7_Powers_Strategic_Power_FRAMEWORKS.docx

## Purpose

Systematically evaluate a business against all seven sources of strategic Power (Scale Economies, Network Economies, Counter-Positioning, Switching Costs, Branding, Cornered Resource, Process Power) to determine competitive durability and identify power gaps.

## When to Use

When a persistent problem resists repeated fix attempts, suggesting the issue is structural rather than personnel-based.

## Instructions

Follow this workflow precisely. Each step is grounded in the source document(s) listed above. Do not skip steps. Do not invent frameworks, models, or terminology not present in the source material. Execute each step in order, using the exact logic and decision criteria documented.

## Workflow

1. Identify the strategically separate business unit. Even businesses within the same corporation must be assessed independently.
2. List all competitors: existing and potential, direct and functional. Power is explicitly relative to each specific competitor.
3. For each competitor, scan all 7 Power types. Check both Benefit and Barrier for each.
4. Apply the 3 S's test to each claimed advantage: Is it Superior (improves free cash flow)? Significant (material improvement)? Sustainable (immune to competitive arbitrage)?
5. Assess Power intensity via Industry Economics and Competitive Position dimensions for each Power type present.
6. Determine the business stage on the Power Progression (Origination, Takeoff, or Stability). Identify which Power windows are open and which are closing.
7. If no route to Power exists, document the gap. Power cannot be planned into existence; it requires invention.
8. Produce a Power Map showing current position, available Power types by stage, and priority actions.

## Output Format

Produce all of the following deliverables:

- A 7-Power scorecard (each Power type rated for Benefit, Barrier, and Intensity)
- A competitor-by-competitor Power comparison matrix
- Power Progression stage classification with open/closing windows
- Priority strategic actions mapped to available Power windows

## Example Use

User provides context about their specific situation. The skill guides them through each workflow step sequentially, producing all deliverables listed in the Output Format section. Each step builds on the previous one, and no step should be skipped.
