# Server Farm Commissioning (Five-Level Hierarchy)

**Skill ID:** 14.1  
**Category:** Data Center Commissioning  
**Source Document(s):** Server_Farm_Commissioning_FRAMEWORKS.docx

## Purpose

Execute data center commissioning through the five-level testing hierarchy with 100% verification, proper governance, and deficiency resolution at each gate.

## When to Use

When commissioning, evaluating, or analyzing data center infrastructure systems.

## Instructions

Follow this workflow precisely. Each step is grounded in the source document(s) listed above. Do not skip steps. Do not invent frameworks, models, or terminology not present in the source material. Execute each step in order, using the exact logic and decision criteria documented.

## Workflow

1. Establish CxA Governance: The Commissioning Authority directs all commissioning activities with full verification authority. 100% verification, no sampling allowed.
2. Level 1 - Pre-Functional Inspection: Verify manufacturing, installation, connections, and controls wiring are correct and complete. Checklists completed by installing contractor, verified by GC.
3. Level 2 - Startup: Vendor-led equipment energization per manufacturer procedures. Pre-functional inspection must be complete first.
4. Level 3 - Functional Testing: Verify each system operates as designed under normal conditions.
5. Level 4 - Integrated Systems Testing (IST): Test multiple systems operating together under simulated failure conditions.
6. Level 5 - Full Building Commissioning: Complete building systems operating under realistic load conditions.
7. At each level: Complete all testing and resolve all deficiencies before advancing to the next level.
8. Document all test results, deficiencies, and resolutions. Owner/OR provides final sign-off on individual tests.

## Output Format

Produce all of the following deliverables:

- Commissioning plan with CxA governance structure
- Completed checklists for each of the five levels
- Deficiency log with resolution status
- Final acceptance documentation signed by Owner/OR
