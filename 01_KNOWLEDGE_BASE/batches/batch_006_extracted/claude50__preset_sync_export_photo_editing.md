# Preset-Sync-Export Photo Editing Pipeline

**Skill ID:** 15.1  
**Category:** Photo Editing & AI Retouching  
**Source Document(s):** evoto_ai_techniques_extraction.docx, Photography_Techniques_Frameworks.docx

## Purpose

Edit photos at scale using the productized pipeline: edit one image to professional standard, save as reusable preset, batch-sync across entire galleries.

## When to Use

When producing professional creative work that needs consistent quality and efficient delivery.

## Instructions

Follow this workflow precisely. Each step is grounded in the source document(s) listed above. Do not skip steps. Do not invent frameworks, models, or terminology not present in the source material. Execute each step in order, using the exact logic and decision criteria documented.

## Workflow

1. Apply the Layered Editing Framework to a hero image: Global corrections (exposure, white balance) > Mid-level adjustments (tone curves, HSL) > Targeted local edits (masking, dodge/burn).
2. Use AI skin retouching with selective preservation: Remove blemishes at 100% while preserving character features (freckles, beauty spots) by dialing specific sliders independently.
3. Apply AI dodge and burn to even skin tones while retaining texture.
4. Set the desired skin texture preset (matte, satin, dewy, or shiny).
5. Save the complete edit as a reusable preset.
6. Batch-sync the preset across the entire gallery.
7. Review synced images for outliers requiring individual adjustment.
8. Export at appropriate resolution and format for delivery.

## Output Format

Produce all of the following deliverables:

- A hero image edited to professional standard
- A reusable preset encoding the complete edit
- Batch-synced gallery ready for client review
- Final exported deliverables
