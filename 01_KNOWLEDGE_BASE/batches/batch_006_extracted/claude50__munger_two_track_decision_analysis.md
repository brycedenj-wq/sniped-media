# Munger Two-Track Decision Analysis

**Skill ID:** 19.1  
**Category:** Mental Models & Multidisciplinary Thinking  
**Source Document(s):** Mental_Models_Worldly_Wisdom_FRAMEWORKS.docx

## Purpose

Analyze every major decision through two simultaneous tracks: Track 1 (rational analysis using multidisciplinary mental models) and Track 2 (psychological analysis using the 25 Standard Causes of Human Misjudgment) to avoid blind spots.

## When to Use

Before any high-stakes decision where cognitive biases could distort judgment.

## Instructions

Follow this workflow precisely. Each step is grounded in the source document(s) listed above. Do not skip steps. Do not invent frameworks, models, or terminology not present in the source material. Execute each step in order, using the exact logic and decision criteria documented.

## Workflow

1. Track 1 - Rational Analysis: Identify which mental models from multiple disciplines apply. Pull from mathematics (compound interest, decision trees), economics (comparative advantage, opportunity cost), biology (competitive exclusion, adaptation), physics (critical mass, feedback loops), and statistics (regression to mean, correlation vs. causation).
2. Track 1 continued: Apply Inversion. Define the desired outcome, then list all the ways to guarantee the opposite outcome (failure). Avoid those failure modes.
3. Track 1 continued: Check for Lollapalooza Effects. Are multiple forces converging in the same direction? When multiple models point to the same conclusion, the combined effect is far greater than any single model predicts.
4. Track 2 - Psychological Analysis: Scan for the top misjudgment tendencies affecting this decision. Priority checks: Incentive-caused bias (#1), Social proof (#5), Commitment/consistency (#8), Deprival superreaction (#14), Envy/jealousy (#10).
5. Track 2 continued: Check yourself. Are you affected by liking/loving tendency, authority influence, or contrast misreaction? The most dangerous biases are the ones affecting YOU.
6. Compare Track 1 and Track 2 outputs: When both tracks point the same direction, you have high conviction. When they conflict, investigate further before deciding.
7. Apply the Circle of Competence test: Can you genuinely understand this? If not, pass. No exceptions.
8. Apply Margin of Safety: Even after both tracks confirm, build in a buffer for being wrong.

## Output Format

Produce all of the following deliverables:

- Track 1 analysis: Multidisciplinary model application with conclusions
- Inversion analysis: How this could fail, and which failure modes to avoid
- Track 2 analysis: Identified psychological tendencies and their likely influence
- A convergence/divergence assessment between both tracks
- Final decision recommendation with margin of safety

## Example Use

User provides context about their specific situation. The skill guides them through each workflow step sequentially, producing all deliverables listed in the Output Format section. Each step builds on the previous one, and no step should be skipped.
