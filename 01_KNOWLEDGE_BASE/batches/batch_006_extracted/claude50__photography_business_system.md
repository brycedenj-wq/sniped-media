# Photography Business System

**Skill ID:** 11.1  
**Category:** Creative Production  
**Source Document(s):** Photography_Business_Frameworks.docx

## Purpose

Build a photography business using the Specialist Positioning Method, P.S.S. Framework (Problem > Solution > Service), and Welcome Pack pricing architecture.

## When to Use

When evaluating business operations, financial structure, or revenue growth opportunities.

## Instructions

Follow this workflow precisely. Each step is grounded in the source document(s) listed above. Do not skip steps. Do not invent frameworks, models, or terminology not present in the source material. Execute each step in order, using the exact logic and decision criteria documented.

## Workflow

1. Choose your specialist positioning: Ask 'Who can I serve better than anyone else with my specific skill set?' Commit exclusively.
2. Identify the specific problem your target audience has with photography/visual content.
3. Create free valuable content that solves that problem and builds authority (P.S.S. Phase 1: Problem identification, Phase 2: Solution education).
4. Design a targeted service that solves the problem completely (Phase 3: Service creation).
5. Build a Welcome Pack: Pre-sales document that filters clients, sets expectations, prevents scope creep, and positions you as premium.
6. Deliver with unexpected extra value that drives referrals.
7. Implement systems over talent: Build client pipeline, delivery workflow, pricing structure, and marketing cadence.

## Output Format

Produce all of the following deliverables:

- Specialist positioning statement
- P.S.S. content-to-client pipeline
- Welcome Pack / pricing architecture document
- Client delivery workflow and operational systems

## Example Use

User provides context about their specific situation. The skill guides them through each workflow step sequentially, producing all deliverables listed in the Output Format section. Each step builds on the previous one, and no step should be skipped.
