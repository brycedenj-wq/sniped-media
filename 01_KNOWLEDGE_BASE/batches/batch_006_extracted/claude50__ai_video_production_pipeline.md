# AI Video Production Pipeline (Kling AI)

**Skill ID:** 11.4  
**Category:** Creative Production  
**Source Document(s):** kling_ai_extracted.docx

## Purpose

Produce consistent AI-generated video using the Image-First Pipeline, Prompt Architecture System, and Consistency System.

## When to Use

When a persistent problem resists repeated fix attempts, suggesting the issue is structural rather than personnel-based.

## Instructions

Follow this workflow precisely. Each step is grounded in the source document(s) listed above. Do not skip steps. Do not invent frameworks, models, or terminology not present in the source material. Execute each step in order, using the exact logic and decision criteria documented.

## Workflow

1. Generate a high-quality reference image (not text-to-video). Specify camera type, lens, skin texture, clothing, environment, lighting, and film grain.
2. Upscale the reference image before animation.
3. Apply the Five-Part Cinematic Prompt: Subject + Action + Environment + Lighting/Atmosphere + Camera Movement.
4. For animation control, use the Four-Layer Video Prompt: Camera/Framing + Primary Motion + Secondary Motion + Detail/Mood.
5. Maintain character consistency using: Elements (multi-angle reference bundles), Style Bible Lines (single style sentence copied across all prompts), and Reference Image Role Assignment.
6. Animate with Kling using image-to-video with the controlled start frame.
7. Upscale the final video output.
8. For multi-shot projects, use Kling 3.0 multi-shot generation to maintain consistency across camera angles.

## Output Format

Produce all of the following deliverables:

- High-quality reference image (upscaled)
- Cinematic prompt library for the project
- Character consistency assets (Elements, Style Bible, Reference assignments)
- Final upscaled video output
