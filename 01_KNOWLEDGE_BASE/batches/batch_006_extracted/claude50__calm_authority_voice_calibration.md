# Calm Authority Voice Calibration

**Skill ID:** 5.3  
**Category:** Communication & Messaging  
**Source Document(s):** Operator_Level_Communication_Frameworks.docx

## Purpose

Calibrate all outbound business communication to project calm authority using the seven-attribute voice model, sentence rhythm system, and authority vocabulary architecture.

## When to Use

When crafting any business communication that needs to be clear, memorable, and drive action.

## Instructions

Follow this workflow precisely. Each step is grounded in the source document(s) listed above. Do not skip steps. Do not invent frameworks, models, or terminology not present in the source material. Execute each step in order, using the exact logic and decision criteria documented.

## Workflow

1. Audit the communication against seven voice attributes: Educated but Accessible, Structured but Human, Calm Authority, Execution-Focused, Visually Aware, Systems-Driven, Modern and Clean.
2. Apply the validation test: Does this sound like someone who has actually done this in the real world?
3. Engineer sentence rhythm: Mix short control sentences (authority), medium explanatory sentences (teaching), and occasional longer synthesis sentences (depth).
4. Select paragraph architecture: Use Control > Insight > Impact for persuasion, or Operator Walkthrough for teaching/documentation.
5. Audit vocabulary: Replace diluting words ('hustle,' 'passion,' 'journey') with authority-reinforcing words ('system,' 'framework,' 'calibration,' 'execution').
6. Strip all filler, decoration, and dated language. Every sentence must earn its place.

## Output Format

Produce all of the following deliverables:

- Revised communication scored against the seven voice attributes
- A vocabulary replacement list (diluting words swapped for authority words)
- A communication that passes the 'has this person actually done the work?' test

User provides context about their specific situation. The skill guides them through each workflow step sequentially, producing all deliverables listed in the Output Format section. Each step builds on the previous one, and no step should be skipped.
