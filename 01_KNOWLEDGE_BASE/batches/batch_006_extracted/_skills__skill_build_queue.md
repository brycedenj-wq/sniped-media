# SNIPED Skills · Build Queue

Every SNIPED doc + book → Claude Skill. Reality check: each skill takes 10-15 min done right. 50+ candidates = several working sessions. This queue is the prioritized build order.

Last updated: 2026-05-12

---

## Discipline

- **One skill per source · don't combine.** Each skill is invokable for one task type.
- **Reference, don't duplicate.** Skills should READ source docs/memory at invocation, not copy content.
- **Frontmatter is load-bearing.** `name` + `description` decide if Claude picks the skill. Write descriptions like search queries.
- **MANDATORY READING section in every skill.** Skill activation = read X, Y, Z before any output.
- **Refuse drift.** Each skill names its lane and refuses out-of-lane requests.

## Build cadence proposal

| Session type | Skills built | Time |
|---|---|---|
| Single focused build session | 3-5 skills | 60-90 min |
| Tier 1 complete (5 skills) | After 1-2 sessions | ~2 hours |
| Tier 2 complete (17 skills) | After 4-5 sessions | ~6 hours |
| All 50 skills complete | After 10-12 sessions | ~15-20 hours total |

**Honest framing:** This is not a one-session project. Sessions need to be dedicated build sessions, not mixed with photo edit / outreach work. Schedule one Saturday Build per week for skills until Tier 1 + Tier 2 complete (~6 weeks).

## Skill installation

Once a skill is built in `/SNIPED_OS/_skills/[skill-name]/`:

1. **For Claude Code CLI:** Copy/symlink to `~/.claude/skills/[skill-name]/`
2. **For Claude Desktop:** Customize Skills → Upload Skill → drag the folder
3. **For Cloud agent:** Upload via the cloud agent setup UI

Skills in `/SNIPED_OS/_skills/` are the canonical source. Installations are deployments.

---

## What is NOT a skill candidate

- Strategic books not yet distilled to intel memory (defer until distilled)
- CRM data, lead lists, financial files (these are data, not workflows)
- Working state files (CURRENT_STATE.md, ACTIVE_THREADS.md, SESSION_LOG.md)
- Memory layer itself (memory is read by skills, not wrapped as skill)
- Source docx files in `/99_VAULT/` (extracted, archived, done)

The rule: skills wrap **workflows** and **decision frames**, not data and not raw sources.
