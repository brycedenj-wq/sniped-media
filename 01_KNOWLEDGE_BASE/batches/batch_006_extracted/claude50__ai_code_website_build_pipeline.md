# AI-Assisted Website Build Pipeline

**Skill ID:** 9.3  
**Category:** AI Systems & Automation  
**Source Document(s):** AI_Code_Website_Building_Extraction.docx

## Purpose

Build professional websites using the layered context architecture (PROJECT.md + Skills + Brand Assets + MCP Servers) with visual QA loops and clone-then-customize workflows.

## When to Use

When building AI-powered workflows, automations, or systems that need to operate reliably at scale.

## Instructions

Follow this workflow precisely. Each step is grounded in the source document(s) listed above. Do not skip steps. Do not invent frameworks, models, or terminology not present in the source material. Execute each step in order, using the exact logic and decision criteria documented.

## Workflow

1. Create the PROJECT.md file: Project description, tech stack constraints, design rules, screenshot workflow instructions, brand asset locations, deployment rules. Keep concise.
2. Install and invoke the Front-End Design Skill before writing any front-end code.
3. Select a high-quality reference site. Screenshot its structure and styling.
4. Clone the reference structure, then layer in your own brand identity, content, and positioning.
5. Enable the Screenshot Loop (Visual QA): AI code agent takes screenshots of its own output via Puppeteer, compares against reference, identifies issues, corrects, and re-screenshots. Minimum two comparison passes.
6. Build with component assembly: Use existing component libraries and skill files rather than building from scratch.
7. Disable screenshot loop for animated/dynamic backgrounds to prevent over-engineering loops.
8. Iteratively refine the PROJECT.md as you discover what the agent needs to be reminded of.
9. Deploy using the production pipeline defined in your PROJECT.md.

## Output Format

Produce all of the following deliverables:

- A PROJECT.md system prompt file
- A professional website built from reference + brand overlay
- Screenshot iteration history showing quality progression
- Reusable skill and component library for future builds

## Example Use

User provides context about their specific situation. The skill guides them through each workflow step sequentially, producing all deliverables listed in the Output Format section. Each step builds on the previous one, and no step should be skipped.
