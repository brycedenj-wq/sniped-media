# Video Editing Assembly-Line Workflow

**Skill ID:** 11.3  
**Category:** Creative Production  
**Source Document(s):** Premiere_Pro_Production_Framework.docx

## Purpose

Edit video efficiently using the five-phase Assembly-Line Sequence with Adjustment Layer methodology and custom keyboard shortcuts for maximum throughput.

## When to Use

When producing professional creative work that needs consistent quality and efficient delivery.

## Instructions

Follow this workflow precisely. Each step is grounded in the source document(s) listed above. Do not skip steps. Do not invent frameworks, models, or terminology not present in the source material. Execute each step in order, using the exact logic and decision criteria documented.

## Workflow

1. Phase 1 - Rough Assembly: Place clips in sequence, establish structure. Do not color grade or add effects yet.
2. Phase 2 - Precision Editing: Trim, pace, add transitions. Map Add Edit and Ripple Delete to custom keys for speed.
3. Phase 3 - Visual Enhancement: Apply color, effects, and text. Use Adjustment Layers for all global effects (sharpening, color correction, vignettes, film grain) instead of clip-by-clip.
4. Phase 4 - Audio Design: Add music, set levels, use Audio Remix for length matching.
5. Phase 5 - Export & Delivery: Final render with appropriate settings.
6. Use Keyframe Velocity Curves for professional motion: Set start/end keyframes with Ease In/Ease Out, adjust velocity curve for fast-start-slow-finish.
7. Use AI object masking for subject isolation instead of manual rotoscoping where available.

## Output Format

Produce all of the following deliverables:

- A completed video edit following the five-phase sequence
- Adjustment layer stack for global effects
- Custom keyboard shortcut profile
- Exported deliverable
