# Freelance Platform Optimization

**Skill ID:** 7.4  
**Category:** Business Operations & Finance  
**Source Document(s):** Freelance_Platform_Strategy_Frameworks.docx

## Purpose

Optimize freelance platform presence (Fiverr/Upwork) using the Visibility-Conversion-Retention funnel, gig-as-sales-page framework, and consultation-first monetization.

## When to Use

When building or optimizing a presence on freelance platforms to attract premium clients.

## Instructions

Follow this workflow precisely. Each step is grounded in the source document(s) listed above. Do not skip steps. Do not invent frameworks, models, or terminology not present in the source material. Execute each step in order, using the exact logic and decision criteria documented.

## Workflow

1. Diagnose the funnel stage: Impressions (visibility problem), Click-Through Rate (thumbnail/title problem), or Conversion Rate (gig page/pricing problem).
2. Optimize the gig as a sales page: Fill portfolio, create process PDFs, add gig video, write detailed FAQ, add strategic extras.
3. For complex projects, sell a paid consultation first: Map client systems, APIs, feasibility, and limitations. Then quote the build separately.
4. Apply the Save Time / Make Money / Enable Scale filter to every project before accepting.
5. Position for the Infrastructure Era: Move from one-off AI tasks ($50) to autonomous system builds ($5,000+).
6. Build multi-platform presence: Fiverr first (inbound), then Upwork (outbound proposals, retainers), then personal brand and social media.

## Output Format

Produce all of the following deliverables:

- Funnel diagnostic with identified weak stage
- Optimized gig page (portfolio, video, FAQ, process PDF, extras)
- Consultation-first pricing structure
- Multi-platform client acquisition roadmap
