# SNIPED Composite Environment Rotation v1

Locked 2026-05-12. The 7-environment world-building vocabulary for SNIPED composite work. This is what separates recognizable SNIPED authorship from random AI composites.

**The core insight:** most AI composite artists fail because they chase novelty (new style every image). SNIPED's instinct is constrained world-building · the world stays consistent, the subjects rotate through it. That's visual infrastructure, not randomness.

### How to use the framework

When planning a chapter (a content sprint of 6-12 frames anchored to one shoot or one theme), run the framework:

1. **What's the emotional role of this chapter's hero frame?** Pick the environment whose emotional role matches.
2. **What's the chapter's placement in the year?** A standalone chapter vs a chapter that bridges between two larger arcs influences environment choice.
3. **What escalation level does this moment deserve?** Don't put Futurist Editorial on a casual Tuesday post · save the 5/5 for the moments that earn it.
4. **Does the subject fit the environment's ideal type?** A casual founder photographed in Sculptural Gallery reads as overcorrection. Match the environment to the subject's actual register.
5. **Does the color relationship serve the subject's skin retention?** All 7 environments are built around #B8956E skin retention against varying shadow + mid-tone palettes. The relationship is always "skin warmth + environment cool/neutral · never compete."
6. **What's the narrative function of this frame in the chapter's story?** Hero / bridge / identity / canon / scene / interior / aspiration. The function names what the frame is DOING, not what it shows.

### The chapter-construction rule

A chapter typically uses ONE environment for its hero + supporting frames. But a longer chapter (8+ frames over weeks) can use a "primary + bridge" pairing:
- Primary: the chapter's central environment (e.g., Brutalist Monument as hero)
- Bridge: ONE supporting environment that creates connective tissue (e.g., Industrial Minimal as the "in-between" register)

NEVER mix 3+ environments in a single chapter. The point of the rotation is recognizable world continuity. Three environments dilute.

### The year-long pacing logic

Across a year of chapters, the 7 environments compose into a body of work. A recommended Phase B+ year:

- Q1: Brutalist Monument (1 major chapter) + Cinematic Urban (1 chapter)
- Q2: Industrial Minimal (1 chapter) + Monochromatic Void (1 chapter)
- Q3: Sculptural Gallery (1 chapter · pairs with Direction Stack book launch as canonization frame) + Organic Surreal (1 chapter)
- Q4: Brutalist Monument (second chapter · the year-end escalation) + Futurist Editorial (1 chapter · max · for the year-end statement)

This gives 8 chapters across the year, with Brutalist Monument bookending and Futurist Editorial as the rare-deployment statement piece. Adjust per actual content but the rotation discipline holds.

### The unified visual hand

Founder lane and creative lane share the same 7 environments. There is no separate creative-lane rotation. The brand is one visual hand across all output. A founder portrait in Cinematic Urban and a creative subject in Organic Surreal both read as SNIPED because the framework holds across both.

**Role:** power · isolation · scale · operator mythology
**Visual traits:** raw concrete · massive negative space · warm shaft light · deep shadows · sculptural geometry

```
Subject placed in massive brutalist concrete architecture.

Warm shaft light from upper right palette #B8956E.

Shot on Mamiya 7 medium format, Kodak Portra 400 grain.

No cinematic theatrics, no teal/orange, no HDR.
Preserve subject identity exactly: face, hair texture, body proportions, skin tone retained.
Quiet luxury, recognizably SNIPED.
```

## The composite is BACKGROUND REPLACEMENT, not subject regeneration

**Critical clarification (2026-05-12):** SNIPED composites use the photographed still as the foundation. The subject's pose, expression, hair, body, identity all stay EXACTLY as captured. Only the background gets generated/replaced. This is NOT AI image generation with the subject as a reference · the subject is the literal photograph.

Two execution paths:

### Path A · Photoshop Generative Fill with Reference Image (fastest · LOAD-BEARING)
1. Open Evoto JPG/PNG in Photoshop
2. Select Subject → Invert selection (background now selected, subject protected)
3. Refine Edge on hair
4. **Add Reference Image** in the Generative Fill panel · upload an architect/photographer reference matching the environment (e.g., Tadao Ando interior for Brutalist Monument)
5. Text prompt addendum (paired with the reference): use the environment template below
6. Choose **Adobe Firefly** model (Reference Image works · Nano Banana in Photoshop does not yet support it)
7. Generate, pick best of 3 variations, accept

Reference Image is the unlock. Text-only Generative Fill gives generic Brutalist. Reference Image targets the specific architectural register. See `/10_REFERENCE/PHOTOSHOP_GENERATIVE_FILL_REFERENCE_IMAGE_EXTRACTION.md` for the full workflow.

Build a reference image library at `/SNIPED_OS/05_PRODUCTION/_composite_references/` organized by environment (3-5 refs per environment). Build once, reuse forever.

### Path B · External AI plate + Photoshop composite (better register match)
1. Generate ONLY the environment plate in Higgsfield Soul / Seedream / Nano Banana (no subject in prompt, "empty interior, no people")
2. Composite in Photoshop: place plate as background layer, mask subject, harmonize at 40-50%, unifying grain

### When to use which
- Path A · default for daily IG posts, fast turnaround
- Path B · when Path A's register reads weak (Brutalist Monument especially benefits from Higgsfield Soul's atmospheric quality)

**Prompt adjustment:** all 7 environment prompt templates above include "Subject placed in [environment]" phrasing because they were written for full-composite generation. For background replacement, replace "Subject placed in" with "Empty [environment], no people, no subjects." Everything else in the prompt (palette, camera cheat code, mood reference) stays.

## AI input format · the universal export step

Higgsfield, Seedream, Nano Banana Pro, Krea · NONE accept TIFF. Always export an AI-input PNG between Evoto and the AI tool:

- **Format:** PNG (preferred · lossless) or JPG Q100 (acceptable)
- **Color space:** sRGB (NOT ProPhoto)
- **Bit depth:** 8
- **Long edge:** 2048px (AI tools compress internally · 6000px wastes bandwidth)
- **Output sharpening:** None
- **Filename:** `[FRAME]_for_ai.png` next to the Evoto TIFF
- **Time cost:** 30 seconds

The TIFF stays as archival master. The PNG is the AI input copy. Only Adobe Firefly accepts TIFF directly · the other tools all need PNG/JPG.

## The single rule

**One environment per chapter. Don't mix. Don't chase novelty.**

The point of the rotation is: the same model across 7 different environments = 7 frames that all feel SNIPED.

Most AI composite artists make 7 frames in 7 different aesthetic universes. The work scatters, identity dilutes, nothing reads as authored.

SNIPED's move: the WORLD stays consistent (one environment per chapter), the subjects rotate. This is visual infrastructure. This is recognizable authorship.
