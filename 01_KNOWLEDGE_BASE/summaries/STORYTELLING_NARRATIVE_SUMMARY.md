## Key signal installed

1. **The Anatomy of Story (Truby):** a story is an organic body with a single designing principle (story process plus original execution); desire is the surface goal the audience tracks while need is the hidden change that makes payoff possible; the true opponent competes for the same goal; theme is a moral vision argued through the character web, not stated.
2. **The Hero with a Thousand Faces (Campbell):** one cross-cultural pattern recurs, departure-initiation-return ("a hero ventures forth... and returns to bestow boons"); it opens with a call to adventure and a common refusal; the initiation runs through a road of trials to an earned ultimate boon; the return (master of the two worlds, freedom to live) is the hardest stage. Held as cultural/narrative pattern study, not faith.
3. **Save the Cat! (Snyder):** nail the logline / one-line first (irony, a vivid mental picture, a killer title, "what is it?"); place the work in one of the ten primal genres and give "the same thing, only different"; use the fifteen-beat sheet to control pacing and a save-the-cat beat to earn rooting interest early.
4. **The Visual Story (Block):** every picture is built from seven basic visual components (space, line, shape, tone, color, movement, rhythm); contrast raises visual intensity and affinity lowers it; the screen is never empty, so plan visual progressions that escalate intensity in step with the story's build.
5. **Synthesis (015):** the operator toolkit (one organic structure around a designing principle, a recognizable arc, premise clarity inside a familiar category, and deliberate visual intensity matched to the build) + the optionality guardrail.
